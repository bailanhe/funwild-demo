> 6 类用户 × 13 子细分。两条核心用户线（本地华人雪友 / 国内来欧游客）共享同一个平台但**永远不应该看到同一个首页**。

## 1. 类型 1 · 欧洲本地华人雪友（Year 1 50% MAU）

> Year 1 的"老用户池"。占注册用户 50%，但**贡献 80% 打卡 / 拼车 / 徽章解锁**。是社区氛围与 UGC 内容的主要来源。

### 1A · Hardcore 玩家（10% · 估算 50 人 / Year 1）

| 维度 | 内容 |
|---|---|
| **画像** | 30-45 岁，在德 / 奥 / 瑞工作 5+ 年，年滑 30-60+ 次，雪季会请年假追雪到日本 / 北美。装备 €3-8K。 |
| **动机** | ① 找同级别的人一起滑（最难） ② 第一时间知道粉雪条件 ③ 装备折扣 ④ 在社群里有"老炮"地位 |
| **焦虑** | 周末和"新手团"绑在一起被迫降速；技术停滞；和女朋友 / 老婆滑不到一起 |
| **使用频率** | 雪季内每日打开 2-3 次；雪季外每周 1-2 次（查下个雪季 / 看 B-kuh / 看徽章） |
| **最重要 action** | 早上 8 点看"今天雪深 / 缆车 / 同级别雪友轨迹"；晚上 9 点看"周末计划" |
| **最担心的问题** | 拼到一个"明明说自己中级，结果第一缆车摔了"的伪中级 |
| **决策逻辑** | 看人，不看雪场。"X 去就去"。 |
| **信任建立方式** | 通过另一个 Hardcore 的拼车 / 教练评价 |
| **为什么愿意留下** | Funwild 是欧洲华人圈唯一让 Hardcore 有"我是 KOL"感的产品 |
| **为什么会流失** | 看到平台变成"新手问答区"，失去精英感 |

**产品 implication**：
- Hardcore 主页要有"我是社区 KOL"感：高徽章计数置顶 + 打卡轨迹可视化 + 被关注数显眼。
- 雪深 / 缆车 / 实时雪况信息要做（Year 2 接入第三方 API）。
- 拼车筛选必须支持"等级匹配"——发拼车时勾"只接受同级别"。
- 徽章中"夏日冰川"、"五国开拓者"、"冰川全家桶"是 Hardcore 专属，普通用户解锁不了。

---

### 1B · 周末玩家（50% · 估算 250 人 / Year 1）⭐ Year 1 主力

| 维度 | 内容 |
|---|---|
| **画像** | 25-40 岁，在德 / 奥工作或读博士。雪季滑 8-15 次。装备 €1-3K。多数有车或常拼车。 |
| **动机** | ① 周末拼车找雪友 ② 找性价比教练带新朋友 ③ 不想错过 N47 活动 ④ 雪季有"打卡感" |
| **焦虑** | 周五晚上发现没人组局；雪场停车不熟；带朋友新手不知道去哪雪场友好 |
| **使用频率** | 周三 - 周日每日打开 1-2 次；周一周二打开 1 次 |
| **最重要 action** | 周三晚看"这周末谁去 Spitzingsee"；周日晚看徽章进度 |
| **最担心的问题** | 没人组局；好不容易组到拼车，发起人临时鸽 |
| **决策逻辑** | 看时间窗口和拼车伙伴的可靠性 |
| **信任建立方式** | 拼车次数 + 准时率 + 共同朋友 |
| **为什么愿意留下** | 周末再也不用一个人在山上 |
| **为什么会流失** | 雪季后 4 个月没东西看；周三推送失灵；雪场列表过时 |

**产品 implication**：
- ⭐ **周三晚 8 点推送是 Year 1 最重要的一个 push 节点**。所有 push 系统优化必须 prioritize 这个。
- 拼车信用分（每次成行 +1，临时取消 -2）必须做。鸽掉的人在主页可见"准时率 85%"。
- 雪季外（5-10 月）必须有 retention 内容：徽章年度复盘海报、明年雪季倒计时、夏季冰川活动、徒步预告。
- 雪场列表的"难度筛选"和"单板友好度"是周末玩家最常用的筛选维度。

### 1C · 新手（30% · 估算 150 人 / Year 1）

| 维度 | 内容 |
|---|---|
| **画像** | 22-30 岁，留学生或第一年工作。雪季 3-8 次，可能还在租板。 |
| **动机** | ① 找便宜中文教练 ② 求带 ③ 想看新手友好的雪场 ④ 学习"应该怎么准备" |
| **焦虑** | 不会说德文怕教练听不懂；担心摔伤；担心被老雪友嫌弃；担心装备不对 |
| **使用频率** | 雪季内每周 1-3 次；雪季外几乎不打开 |
| **最重要 action** | 第一次打开看"新手指南"；找新手友好的活动报名 |
| **最担心的问题** | 报了一个团结果发现自己最菜；找的教练不会中文 |
| **决策逻辑** | 看评价多 + 难度低 + 标"新手友好" |
| **信任建立方式** | 看到学员评价里有"和我一样的新手"语句 |
| **为什么愿意留下** | 第二个雪季还在；徽章给了进步可视化 |
| **为什么会流失** | 摔了一次没人安慰；上完一次课觉得贵不划算；下个雪季没人组局 |

**产品 implication**：
- 教练页必须有"新手友好" tag + "适合学员级别"明确标注。
- 雪场页"新手一日动线"是 1C 用户最重要的内容。
- 第一个雪季解锁的徽章（如"首次出发"、"初次打卡"）必须设计成"晒朋友圈不丢人"的视觉。
- 新手担心被嫌弃 → 拼车信息中不能让发起人"挑等级"（避免新手觉得被排斥）。但发起人可以选"愿意带新手"开关。

### 1D · 社交型（10% · 估算 50 人 / Year 1）

| 维度 | 内容 |
|---|---|
| **画像** | 24-35 岁女性比例高，单板。年滑 10-25 次但其中 50% 时间在 Après-ski / 拍照 / 装备搭配。 |
| **动机** | ① 拿好看的徽章 ② 海报视觉 ③ 朋友圈点赞 ④ N47 群体认同 |
| **焦虑** | 没人和我一起拍；徽章视觉丑；海报不能发朋友圈 |
| **使用频率** | 每周 2-5 次（高于实际滑雪频率） |
| **最重要 action** | 解锁徽章 → 发海报；浏览其他人徽章墙；逛装备 |
| **最担心的问题** | 海报里 logo 太大破坏画面；徽章撞色 |
| **决策逻辑** | 看视觉，看朋友是否有同款 |
| **信任建立方式** | 看到 KOL 在用 |
| **为什么愿意留下** | 徽章 + 海报 + 用户公开主页让她有"我是 ski girl"的身份感 |
| **为什么会流失** | 徽章设计被吐槽过时；海报模板半年没更新；圈子里大家都不发 Funwild 了 |

**产品 implication**：
- 海报视觉的天花板由 1D 用户决定。设计师产能必须前置投入这里。
- 用户公开主页（V1.1）的展示必须美观，可作为"我的 ski profile"分享到小红书。
- 徽章中"装备控"、"雪联国大使"、"幸运儿"、"夏日冰川"等是 1D 用户偏爱的"非战斗"徽章。
- 1D 用户的 UGC 质量极高（颜值 + 表达欲），是品牌方最想投放的对象。Year 2 可考虑 KOL 计划。

## 2. 类型 2 · 国内来欧洲旅游用户（Year 1 80% 营收）

> Year 1 的"现金牛"。占注册用户 30%，但客单价 €1.5-12K，是地接 / 教练单单的主要来源。

### 2A · 高消费家庭（20% · 估算 60 人 / Year 1）

| 维度 | 内容 |
|---|---|
| **画像** | 35-50 岁，孩子 6-15 岁。一线城市，企业主 / 高管 / 二代。家庭年收入 100W+ RMB。 |
| **客单价** | €5,000-12,000 / 家庭 / 行程 |
| **决策周期** | 3-6 个月 |
| **动机** | ① 让孩子上欧洲顶尖滑雪课 ② 自己也能放松（不用全程陪滑） ③ 朋友圈晒孩子 ④ 体验"真正的欧洲生活" |
| **焦虑** | 孩子安全；语言；医疗；行程不踩坑；钱花得是否值 |
| **决策核心** | "我把孩子交给谁我放心"——教练的资质、医疗保险、紧急联络 |
| **信任建立方式** | 看到家长群里有人推荐；看到教练有 DSLV 认证 + 带过国内学员；地接有保险 + 24h 应急 |
| **使用频率** | 决策期前 4-12 周每周浏览 2-3 次；行中每天打开 1-2 次；行后 1-2 周写攻略 |
| **最重要 action** | 行前：搜索"欧洲滑雪 家庭"+ 看教练 + 询价定制；行中：联系地接 + 打卡 + 找紧急联系；行后：写攻略 + 解锁徽章 |
| **最担心的问题** | 孩子摔伤后续；语言不通买不到保险；地接跑路 |
| **为什么愿意留下** | 全家徽章墙 + 行后写攻略获得"我是欧洲滑雪老炮"的母亲 / 父亲身份 |
| **为什么会流失** | 一次不愉快经历（教练不专业 / 地接出问题）就再也不来 |

**产品 implication**：
- 教练页对 2A 用户必须显示"已带过国内家庭" + "有 First Aid 资质" + "孩子年龄段"。
- 地接项目页"安全保障"模块必不可少：保险条款 + 紧急联系人 + 退改政策。
- 行前 7 天 push："家庭装备清单"+"紧急联系卡片"+"行李清单 PDF"。
- 2A 用户对**纸质 / PDF**有偏好（行程打印出来给家人 / 助理）。"发送 PDF 到我的微信"必须做。
- 2A 写的行后攻略 SEO 价值极高（"欧洲滑雪 家庭 攻略" 是高价值长尾词）。

### 2B · 年轻自由行（40% · 估算 120 人 / Year 1）⭐ 营收主力

| 维度 | 内容 |
|---|---|
| **画像** | 25-35 岁，情侣 / 朋友 2-4 人。北上广深 + 杭州成都，互联网 / 金融 / 创意行业。 |
| **客单价** | €2,000-4,000 / 人 / 行程 |
| **决策周期** | 1-2 个月 |
| **动机** | ① 性价比高的滑雪假期 ② 出片率高 ③ 在小红书有故事讲 ④ 体验欧洲滑雪文化 |
| **焦虑** | 攻略不准踩坑；语言；签证；最后行程乱 |
| **决策核心** | "性价比 + 不踩坑 + 出片"——攻略深度 + 雪场颜值 + 教练价格 |
| **信任建立方式** | 小红书 KOL 推荐；Funwild 攻略详细程度；教练页有真实学员评价 |
| **使用频率** | 决策期 2-4 周每周 4-5 次；行中每天 3-5 次；行后 1 周写笔记 |
| **最重要 action** | 行前：浏览雪场攻略 + 看教练 + 加客服微信咨询；行中：打卡 + 拍照 + 群里发；行后：在小红书发攻略 |
| **最担心的问题** | 攻略说有的设施实际没有；教练不靠谱被坑；地接报价不透明 |
| **为什么愿意留下** | 行后写攻略获得徽章 + 海报很好看 + 下次想再来 |
| **为什么会流失** | 攻略被发现复制粘贴；教练价格虚高；地接报价踩坑 |

**产品 implication**：
- 雪场攻略页是 2B 决策的主战场。必须有 ❗ 特别提醒 + 高清雪场图 + 新手 / 进阶动线 + 教练联动 + 真实评价。
- 教练页必须有透明价格（不是"详询"）+ 已带学员的笔记链接（如果用户在小红书发了）。
- 2B 用户的小红书内容是 Funwild 最重要的获客资产。Year 1 必须有"用户在小红书 #趣野Funwild 笔记列表"页面。
- 行后 7 天 push："把这次旅行写成攻略可得 3 个徽章" + 提供攻略模板（Markdown / 海报）降低写的成本。
- 客服微信咨询通道必须做（Year 1 用人工，贺安祺）。2B 用户在决策期会有大量长问题。

### 2C · 轻奢用户（25% · 估算 75 人 / Year 1）

| 维度 | 内容 |
|---|---|
| **画像** | 30-45 岁，单身 / 情侣 / 朋友。一线城市高净值（投行 / 律师 / 医生）。每年 1-2 次海外滑雪。 |
| **客单价** | €4,000-8,000 / 人 |
| **决策周期** | 1-3 个月 |
| **动机** | ① 体面的滑雪假期 ② 私人化服务 ③ 个性化体验 ④ 不想跟大众团 |
| **焦虑** | 体验大众化 / 不够"个性"；服务质量不达预期 |
| **决策核心** | "私人 + 高品质 + 不大众"——单独教练、私人地接、高端住宿 |
| **信任建立方式** | 一对一咨询的响应速度 + 服务商的高端案例 + 价格匹配预期 |
| **使用频率** | 决策期 1-2 周深度浏览；行中每日 1-2 次；行后较少分享 |
| **最重要 action** | "我要定制" 入口 → 留资 → 私聊地接 |
| **最担心的问题** | 沟通慢；定制不灵活；价格不透明 |
| **为什么愿意留下** | 每年一次高质量定制服务 + 私人雪场身份感 |
| **为什么会流失** | 一次定制不满意；社交圈里没人提 Funwild；找到更"专业"的高端 OTA |

**产品 implication**：
- "我要定制"入口必须 24h 内回复（贺安祺 + 磊子）。响应速度比内容深度更重要。
- 地接页面要有"高端 / 标准 / 经济"三档明示，让 2C 用户快速过滤。
- 2C 用户对**对外形象**敏感——徽章页设计不能太"游戏感"，要"轻奢"。
- Year 2+ 可推"Funwild Concierge"私人订制服务，€2,000-5,000 服务费。

### 2D · 新手体验用户（15% · 估算 45 人 / Year 1）

| 维度 | 内容 |
|---|---|
| **画像** | 25-40 岁，第一次出境滑或第一次出境游。二线城市 / 一线非高净值。 |
| **客单价** | €1,500-3,000 / 人 |
| **决策周期** | 2-4 周 |
| **动机** | ① 想体验欧洲滑雪 ② 一站式不用自己安排 ③ 跟团但不要太多人 |
| **焦虑** | 自己安排不来；语言 0；机票签证不会；想要"全程托管" |
| **决策核心** | "有人接应 + 不用自己做决定 + 不要太贵" |
| **信任建立方式** | 看到客服秒回 + 攻略简单易懂 + 老客户评价提到"全程贴心" |
| **使用频率** | 决策期 1-2 周 + 行中 + 行后 1 次 |
| **最重要 action** | 浏览"首次去欧洲滑雪 一站式" → 加客服 → 报名打包团 |
| **最担心的问题** | 沟通麻烦；自己跟不上团；钱不够 |
| **为什么愿意留下** | 第一次体验好 + 第二次还来（升级到 2B） |
| **为什么会流失** | 体验一次后觉得"我自己也能搞定"了，下次自由行 |

**产品 implication**：
- 2D 用户决策时**强依赖即时聊天**而不是深度内容。Year 1 客服必须配人（贺安祺）。
- Website 应该有"我是新手"专题页：极简攻略 + 一键报名打包团 + 客服二维码。
- 2D 用户进入小程序后看到的是"打包团"+"全程托管"+"客服咨询"，而不是"自己拼车 / 找教练"。

## 3. 类型 3 · 教练（供给侧）

> Year 1 目标 20 个认证教练。教练是 Funwild marketplace 的核心资产。

### 3A · 职业教练（30% · 估算 6 人）

| 维度 | 内容 |
|---|---|
| **画像** | 28-50 岁，DSLV Level 2-3 / 瑞士滑雪联盟认证。雪季全职，年收入 €30-80K。 |
| **动机** | ① 长期客源 ② 个人品牌 ③ 排课工具 ④ 接到高客单价学员 |
| **核心需求** | 个人页 SEO、评价系统、行程发布、接单工具 |
| **使用频率** | 雪季内每日打开 1-2 次；雪季外 1 周 1 次 |
| **最重要 action** | 每周日晚发布"我下周在哪个雪场" |
| **最担心的问题** | 被绕单 + 被骚扰 + 评价被刷差评 |
| **平台价值感知** | "Funwild 给我个人页 + N47 学员流量 + 评价沉淀，比朋友圈强 5 倍" |
| **流失原因** | 觉得平台没流量 / 评价系统不公平 |

**产品 implication**：
- 教练后台必须**极简**：发布"下周行程"3 步内完成；查看待回复 wave 1 步。
- 个人页 SEO 优化（独立 URL + meta + 学员评价聚合）。
- 评价分两种来源：① 平台撮合（带"Funwild 撮合"标签）② 教练手动添加（带"老学员"标签，需要学员在平台确认）。
- 24h 回复率徽章——回复慢的教练在列表里降权。

---

### 3B · 兼职教练（70% · 估算 14 人）

| 维度 | 内容 |
|---|---|
| **画像** | 25-40 岁，本职工程师 / 学生 / 自由职业。BASI 1 / DSLV Level 1 或 N47 内训。 |
| **动机** | ① 周末赚外快（€100-300 / 天） ② 社群认同 ③ 教课中获得成就感 |
| **核心需求** | 简单挂个人页 + 偶尔接单 + 不被打扰 |
| **使用频率** | 雪季内每周 1-2 次；雪季外几乎不打开 |
| **最重要 action** | 看 wave 通知 + 简单回复 |
| **最担心的问题** | 入驻费太贵；规则太复杂；占用本职时间 |
| **平台价值感知** | "免费试试，能接到 1-2 个学员就值了" |
| **流失原因** | 第一年没接到学员；规则越来越复杂 |

**产品 implication**：
- 入驻流程必须 < 10 分钟。包含：基本信息 + 1 张证书照 + 1 张滑雪照 + 自我介绍 100 字。
- 首批 5-10 个兼职教练免费入驻（BP V7 已定）。
- 兼职教练通常不主动管理"行程发布"。Year 1 接受这一点，不要把"行程发布"做成必填。
- 兼职教练的"价格区间"通常含混（"看情况"）。允许标"€60-120 / 小时，详询"。

## 4. 类型 4 · 地接服务商（供给侧）

> Year 1 目标 10 家认证地接。

### 4A · N47 作为地接

| 维度 | 内容 |
|---|---|
| **特殊身份** | gemeinnütziger Verein，享受"N47 官方"专属标签 |
| **服务定位** | 体育推广型（Zweckbetrieb）：大众团、青训营、滑雪体验 |
| **客单价** | 较亲民（€200-1000 / 人 / 团） |
| **平台价值** | 战略合作 + 内容贡献 + 信任背书 |
| **限制** | 不能涉及商业地接（高端家庭定制要走 Funwild 公司账） |

**产品 implication**：
- N47 活动免费上架（BP V7 § 2.3.2）。
- N47 在地接列表中有专属"N47 官方"金色标签。
- N47 的项目页可以放"非盈利说明 + 体育推广目的"。

---

### 4B · 商业地接（个人 + 公司）

| 维度 | 内容 |
|---|---|
| **画像** | 在欧洲有 5+ 年居留，做过滑雪团 / 旅行业。可能是个人 freelancer 也可能是小公司。 |
| **动机** | ① 平台获客 ② 减少自己做营销的工作量 |
| **核心需求** | 项目展示 + 客户咨询导流到自己微信 |
| **入驻焦虑** | "我把客人导到 Funwild 平台上，会不会被平台抢走？" |
| **使用频率** | 雪季内每日打开 1 次；雪季外 1 周 1 次 |
| **最重要 action** | 更新项目状态 / 回复定制需求 |
| **最担心的问题** | 平台不导流 + 平台抽佣高 + 客户被竞争对手看到 |
| **流失原因** | 6 个月没接到单 |

**产品 implication**：
- 地接项目的所有 CTA（咨询 / 联系 / 报价）**直接跳转到地接的微信**，平台不接管对话。这是 4B 入驻的关键信任前提。
- 项目页"已成团"标签需要地接上传真实合影才解锁。防止虚假展示。
- 转介佣金（BP V7 § 2.3.3）的浮动制（5-10%）已经定，Year 1 严格执行。

## 5. 类型 5 · 品牌方（供给侧）

> Year 1 目标 3 家品牌签约。

### 5A · 装备品牌（Nitro / elooa / Burton / 雪具品牌等）

| 维度 | 内容 |
|---|---|
| **画像** | 欧洲华人滑雪圈知名品牌的中文区市场负责人，或品牌的中国经销商。 |
| **动机** | ① 精准触达欧洲华人滑雪用户 ② 测试营销 ROI ③ 试板 / 试装备的活动落地 |
| **焦虑** | "Funwild 流量小，€2,000 花得值吗？" |
| **决策周期** | 1-2 个月，需要数据 + 试投放 |
| **最重要决策依据** | 实测曝光数据 + 历史 ROI 案例 |
| **平台价值感知** | "1500 用户但 100% 精准 + 平台撮合可控" |

**产品 implication**：
- Year 1 给品牌方"广告位实时数据看板"，每天看曝光 / 点击 / 转化（即使是估算）。
- 首年合作套餐 €2,000 是 BP V7 已定，要打包雪场植入 + 活动推荐位 + 教练冠名。
- 品牌方活动（试板 / 训练营）通过"活动板块品牌方专属入口"上线，€50 / 条或 €500 / 年套餐。

## 8. 给设计 / 产品的关键 implication 汇总

1. **首页必须按用户类型分流**——本地华人雪友进入小程序，国内游客进入 Website。同一个"首页"在不同入口下渲染不同内容。
2. **拼车功能围绕周末玩家（1B）打磨**——他们是 50% 主力，所有 retention 都依赖周三晚 push + 周末打卡循环。
3. **教练页围绕国内游客（2A/2B）信任建立**——突出"中文"+"已带过国内学员"+"24h 回复率"。
4. **海报视觉围绕社交型（1D）+ 年轻自由行（2B）调性**——颜值天花板由这两类用户决定。
5. **新手友好（1C/2D）需要单独动线**——不能简化为"和 Hardcore 用同一个 UI"。新手有专属雪场标签 + 教练标签 + 活动标签。
6. **2A 高消费家庭的客服必须配人**——€5-12K 客单价的决策不能靠 FAQ 解决。
7. **教练 / 地接的后台必须极简**——他们不是科技产品用户，复杂后台 = 不用。
8. **品牌方的"数据透明"是 €2,000 套餐复购的关键**——每天看见数据 > 季度总结报告。
