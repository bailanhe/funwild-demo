# Funwild · 协议要点骨架（内部 · 给律师起草用）

> ⚠️ **内部文件,请勿外传。** 这是**要点清单**,供德国/中国律师起草正式文本,本身不是可直接生效的法律文件。作者非执业律师。
>
> 两份核心协议:**A. 用户协议(C 端)** · **B. Provider 入驻协议(B 端)**。另附 C. 各业务线专项条款、D. 隐私政策要点。

## A. 用户协议（C 端 · Terms of Service）

### A1. 平台定位（最重要,反复强调）
- Funwild 是**信息撮合 / 展示平台**,**不是**服务提供方、不是教练/地接/向导的雇主或代理、不组织任何线下活动。
- 用户与 provider 之间的服务关系**直接成立于双方之间**;Funwild 非合同一方。
- 平台对 C 端免费;不收取、不代收、不托管任何课费/团费/租金。

### A2. 责任划分与免责
- 线下活动的安全、质量、履约**由 provider 与用户自行负责**。
- 户外/雪上运动为**固有高风险活动**,用户**自甘风险**,应自行评估自身能力、购买保险、做好安全准备。
- 平台不担保 provider 的资质真实性之外的任何事项(水平/安全结果/履约)。
- 在法律允许范围内,**限制/排除**平台对间接、附带、人身损害的责任(注:欧盟消费者法对免责有强制限制,具体由律师按法域裁剪——不能简单"一免了之")。

### A3. 「已核验」标的法律含义
- 明确"身份已核验 / 资质已核验"**仅表示**平台核对了相应文件**真实存在**,**不构成**对 provider 能力、服务质量或安全结果的担保或推荐。

### A4. 用户义务
- 提供真实信息;遵守雪场规则、当地法律、安全须知;完成高风险活动前的安全确认。
- 不得利用平台从事违法/欺诈/骚扰。

### A5. 高风险活动专门同意（野雪/登山/雪上）
- 单独的**风险告知 + 知情同意**条款;勾选式确认,**带时间戳存档**。
- 强烈建议用户自购户外/医疗/搜救保险。

### A6. 内容与知识库免责
- 安全/攻略内容为**教育科普**,非专业个性化指导;以官方公告(雪崩/天气/FIS)为准。

### A7. 争议解决
- **适用法律 + 管辖**(德国 GmbH 为欧洲经营主体 → 大概率德国法/法院;中国用户的可执行性单独评估)。
- 投诉/通知-移除机制(DSA)。

### A8. 其他
- 账户、终止、修改条款、可分割性、数据(指向隐私政策)。

## B. Provider 入驻协议（B 端 · 教练/地接/向导）

### B1. 关系定性
- Provider 是**独立第三方经营者**,非 Funwild 雇员/代理/合伙人。
- Funwild 仅提供展示/撮合/引流;不参与定价、不抽佣(Year-1)、不碰交易资金。

### B2. 资质与保险（入驻硬门槛）
- 须提供真实身份 + 资质文件(教练证/营业执照等)。
- **强制证明教学期间有有效的职业责任险覆盖** —— 覆盖来源**二选一**:
  - (a) 挂靠滑雪学校的 **Betriebshaftpflicht** 已覆盖自由教练(很多德/奥学校已含,教练大概率 0 成本);或
  - (b) 教练**自购 Berufshaftpflicht**(个人滑雪教练险通常不贵)。
  - ⚠️ **私人责任险(Privathaftpflicht)不算** —— 它排除商业教学。
- **保单覆盖范围核验**:① 人身伤害(Personenschäden)② **接课国家**(德国保单未必覆盖奥/意/法,需 Europaweite Deckung)③ **野雪/山地**(标准教练险常排除,touring 需专门覆盖)。
- 平台**核验保单 + 有效期**;失效即下架提醒。**保险由 provider 自持,平台不代买/不统保**(代买会把平台推向"组织者")。
- 地接须自证旅游经营资质 + 旅游经营责任险 + **破产保障**(对应一揽子旅游指令)。

### B3. Provider 的责任与赔偿（Indemnity）
- Provider 对其服务的安全/质量/履约**独立负全责**。
- **赔偿条款**:因 provider 服务或其资质不实导致的索赔,provider **赔偿并使平台免责**(indemnify & hold harmless)。

### B4. 信息真实性
- 保证上传资质/介绍真实;虚假即违约 + 即时下架 + credit 清零 + 可追责。

### B5. 行为规范与处置
- 禁止把用户导出平台规避规则(视商业策略定)、禁止欺诈/骚扰/超额收费。
- 平台对违规的处置权(警告/下架/封禁)。

### B6. 费用
- 年费(SaaS 性质)条款;明确**不**就交易抽佣(Year-1)。

### B7. 知识产权 / 数据 / 终止 / 适用法
- Provider 内容的使用授权;数据处理;终止与下架;适用法律与管辖。

## C. 各业务线专项条款（挂在 A/B 下）

| 业务 | 必加条款 |
|---|---|
| 拼车 | "仅成本分摊(AA 油费/过路费),非营运、非营利";平台不组织、不担保车辆/驾驶;车祸由参与者自负。 |
| 装备出租 | P2P 出租,平台不检验装备;固定器须专业调试;押金/归还为用户间约定;平台不担保装备安全/适用。 |
| 二手市集 | 平台不介入交易;自行验货面交;旧货风险自担。 |
| 野雪/登山 | A5 高风险同意 + B2 强制山地/雪崩资质与保险。 |
| 地接 | "行程由 provider 提供并负责,Funwild 仅信息展示";禁止平台内打包成交。 |

## D. 隐私政策要点（PIPL + GDPR 双合规）

- 收集范围、目的、法律基础(同意/履约/合法利益)。
- **跨境传输**(China↔EU)合法机制:SCC / 单独同意 / 认证等。
- 用户权利(访问/更正/删除/撤回同意)。
- 数据保留期限;安全确认勾选记录的留存(既是合规也是抗辩证据)。
- 微信生态数据、第三方 SDK 披露。
