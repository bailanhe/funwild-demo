# Funwild · 法律风险矩阵与缓解清单（内部 · 律师输入用）

> ⚠️ **内部文件,请勿外传。** 本文件是给德国/中国律师的**输入草稿**,非法律意见。作者非执业律师。所有结论须经 DACH(德奥瑞)当地律师 + 中国律师正式确认。
>
> 版本:Year-1 草案 · 假设:中国实体 + 德国 GmbH;平台完全不碰交易资金;地接仅引流不在平台打包成交。

---

## 0. 一句话定位

Funwild 的全部法律策略 = **把自己牢牢钉在「信息中介」一侧,而不是「组织者 / 背书者 / 安排者」一侧。** 每个产品/商业决策都按这个标尺评估。

```
纯信息中介 ←──────────────────────────→ 组织者/背书者/安排者
(责任低)        撮合平台    认证+推荐    自营/包办  (责任高)
  目标位置 ↑（信息中介，偶尔轻撮合）
```

---

## 1. 三个结构性决策（已定）

| 决策 | 选择 | 法律作用 |
|---|---|---|
| 实体 | 中国实体（小程序备案/国内运营）+ 德国 GmbH（欧洲经营+有限责任+保险载体） | 责任隔离;出事被告的是有限责任+投保的德国壳 |
| 资金 | **完全不碰**用户↔provider 的交易资金;仅收 provider 年费(SaaS 性质) | 强化中介地位;避开支付牌照(PSD2/支付牌照)、反洗钱、托管担保责任 |
| 地接成交 | Year-1 **仅引流**,provider 自己签约成交;**不**在平台内打包下单 | 避开欧盟一揽子旅游指令(2015/2302)的组织者严格责任 + 强制破产保障金 |

## 2. 关键法律基础（须逐条找律师确认适用性）

| 法域 | 法规 | 对 Funwild 的含义 |
|---|---|---|
| 中国 | **电子商务法 第38条** | 对关系**消费者生命健康**的商品/服务,平台负**资质审核 + 安全保障义务**;未尽到 → 承担**相应的责任(可达连带)**。滑雪教学/野雪/地接全部踩"生命健康"。**这是认证标的核心风险来源。** |
| 中国 | 个人信息保护法 (PIPL) | 中国用户个人信息;跨境(China↔EU)传输需合法基础 |
| 欧盟 | **一揽子旅游指令 2015/2302** | 若平台组合/促成两类以上旅游服务(住宿+缆车+教练) → 可能成"组织者"(严格责任)或 LTA(破产保障义务)。**Year-1 用"仅引流"规避。** |
| 欧盟 | 数字服务法 (DSA) | 中介/托管服务的内容责任、通知-移除机制、透明度义务 |
| 欧盟 | 不公平商业行为指令 / 德 UWG | **误导性陈述**——"认证"若暗示担保而实际未担保 = 风险点 |
| 德国 | BGB(民法典)侵权 / Garantenstellung | **自愿承担的注意义务**:一旦表示"我把关",即产生把关义务,把关不力=过错。**认证标 = 自愿承担。** |
| 德国 | PBefG(客运法) | 拼车收费超过成本分摊 → 可能构成需牌照的客运 |
| 德国/欧盟 | 产品责任指令 | 出租装备缺陷致伤 → 产品责任 |
| 瑞士 | OR(债法)等 | 瑞士非欧盟,部分指令不直接适用,单独看 |

## 3. 风险矩阵（按业务线）

> 等级:🔴 高 / 🟠 中 / 🟡 低-中 / 🟢 低。可能性 × 后果严重度。

### 3.1 野雪 / 登山滑雪教练 — 🔴 最高
- **风险**:雪崩 / 坠落致死或重伤;平台做了"进阶/野雪"背书。
- **为何最高**:死亡后果 + 平台背书 + 生命健康类(中国电商法38条) = 最坏组合。
- **缓解**:
  - [ ] 该类教练**强制**上传山地/雪崩资质 + **职业责任险**,否则不得上架。
  - [ ] 下单前**强制安全确认清单**(已实现),勾选**带时间戳留证** = 知情同意。
  - [ ] 信任标收窄为"资质已核验"事实陈述(已实现) + 免责说明(已实现)。
  - [ ] 用户协议:野雪为高危自甘风险活动,平台不参与组织、不担保安全结果。
  - [ ] 考虑 Year-1 对"平台撮合的野雪私教"设更高门槛,或暂不主推最高危子类。

### 3.2 地接 / 深度团 (outfitter) — 🔴 高（监管性）
- **风险**:欧盟一揽子旅游指令把平台认定为组织者 → 对整个行程严格责任 + 强制破产保障金。
- **缓解**:
  - [ ] Year-1 **仅信息展示 + 引流**,用户与地接**直接成交**(已是 demo 现状:扫码/咨询团长,无平台 checkout)。
  - [ ] **禁止**在平台内做"一次下单组合住宿+缆车+教练"的结账流程。
  - [ ] 要求地接自证其旅游经营资质 + 破产保障 + 责任险。
  - [ ] 页面明示:"行程由 [地接] 提供并负责,Funwild 仅提供信息展示。"

### 3.3 道内滑雪教练 — 🟠 中高
- **风险**:教学中受伤;认证标放大责任。
- **缓解**:同 3.1 的核验/保险/免责/协议,门槛可略低于野雪。

### 3.4 拼车 — 🟠 中
- **风险**:① 车祸人身伤害;② 收费超成本分摊 → 德/奥非法营运(PBefG)。
- **缓解**:
  - [ ] 产品文案锁死"**仅 AA 油费 / 过路费,非营利、非营运**"(分摊成本 ≠ 营运)。
  - [ ] 禁止平台促成超额收费 / 抽成。
  - [ ] 明示:拼车是雪友自行约定,平台不组织、不担保车辆/驾驶。

### 3.5 装备出租 — 🟡 中
- **风险**:出租装备(尤其固定器 DIN 设置)缺陷致伤 → 产品责任 / 出租方责任。
- **缓解**:
  - [ ] 明示出租为用户间 P2P,平台不检验装备;固定器需由专业店调试。
  - [ ] 押金/归还为用户间约定;平台不担保装备适用性与安全。
  - [ ] 高风险品类(固定器/雪鞋绑定)加风险提示。

### 3.6 二手市集 — 🟢 低-中
- **风险**:旧货产品责任、欺诈。
- **缓解**:已写"平台不介入交易"(保持);credit/举报机制;明示自行验货面交。

### 3.7 安全知识内容 — 双刃
- **风险**:若内容有误导致依赖受伤,可能担责;且"提供安全内容"可能被解读为承担了安全责任。
- **缓解**:
  - [ ] 内容定位为**教育/科普,非专业指导**,显著免责。
  - [ ] 引用权威来源(各国雪崩公告、FIS 守则),不发布平台自创的安全判断。
  - **净效应**:框定得当,安全内容**利大于弊**(体现尽责 + 知情同意工具)。

## 4. 跨业务的通用缓解措施（清单）

- [ ] **实体**:德国 GmbH 作为欧洲经营/签约/担责主体;中国实体管小程序备案+国内。
- [ ] **保险(分类核验)**:
  - 平台层:一般责任险 / D&O / 内容责任。
  - **Provider 职业责任险(入驻校验,二选一来源)**:挂靠学校 Betriebshaftpflicht 覆盖,或自购 Berufshaftpflicht。**私人责任险(Privathaftpflicht)不算**(排除商业教学)。
  - **覆盖范围必须核验**:① 人身伤害 ② 接课国家(德国保单未必含奥/意/法,需 Europaweite Deckung)③ 野雪/山地(标准教练险常排除)。
  - 保险**由 provider 自持,平台不代买/不统保**(代买→推向"组织者")。
  - 给教练引导:先问挂靠的 Skischule 是否已覆盖自由教练(多数已含,大概率 0 成本)。
- [ ] **不碰钱**:维持;任何"担保交易/押金托管"功能都会破坏中介地位,慎加。
- [ ] **协议**:用户协议 + provider 入驻协议(见 `agreements-outline.md`);明确中介定位、责任划分、适用法与管辖。
- [ ] **核验 ≠ 背书**:信任标只做事实陈述(已实现);全程避免"推荐/担保/认证靠谱"措辞。
- [ ] **知情同意留证**:安全确认清单勾选**带时间戳存档**,作为抗辩证据。
- [ ] **DSA 合规**:通知-移除机制、举报、透明度。
- [ ] **数据**:PIPL + GDPR 双合规,跨境传输合法基础。
- [ ] **内容免责**:安全/攻略内容统一免责声明。

## 5. 待律师拍板的开放问题

1. 德国 GmbH 是否足够,还是需要额外的旅游/中介牌照?
2. 平台"撮合"野雪私教,在中国电商法38条下是否仍触发资质审核+安全保障义务的连带?如何最小化?
3. "仅引流"的地接,怎样的页面措辞与跳转方式才能稳稳落在"非组织者/非 LTA"?
4. 拼车"成本分摊"的安全边界(每公里上限?)在德/奥/瑞分别如何界定?
5. 信任标"已核验"的措辞,在 UWG / 消费者法下是否仍有误导风险?需不需要进一步弱化?
6. 中国用户在何种情形下能在中国法院起诉德国 GmbH?管辖与执行如何?
7. 保险方案:平台层 + provider 层的最低保额与险种组合。
8. **滑雪教练险细节(找保险经纪确认)**:① 个人 Berufshaftpflicht 的市场保费/最低建议保额;② 学校 Betriebshaftpflicht 覆盖自由教练的普遍程度与确认话术;③ Europaweite Deckung(跨国授课)哪些方案含;④ 野雪/touring 需要的专门险种;⑤ 平台核验保单到"看一眼" vs "持续校验有效期"的尽责边界。
9. **兼职/非全职教练的合法经营资格**:德(Gewerbe?)/奥(Skischule 垄断?)/瑞各自,考了证的个人有偿教学的合法门槛;"雪友陪滑·成本分摊"能否避开奥地利 Skischule 管制。
