# Part 9 · 信任与安全 · Trust & Safety

> "信任来自留痕，不来自承诺。" · GDPR · 微信审核合规

---

## 0. 核心原则

> **教练 / 地接的认证不是 badge，是行为轨迹。**

Funwild **不给徽章式认证**（"已认证教练"四个字），而是让用户**自行判断**：
- 教练靠不靠谱 = 看打卡轨迹 + 学员评价 + 24h 回复率
- 地接靠不靠谱 = 看已成团合影 + 历史评价 + 取消政策

平台只做"留痕"，让真实数据自己说话。

## 1. 教练信任体系

### 1.1 4 层信任信号（详见 part_06_page_ux/04_coach_detail.md）

| 层 | 信号 | 实现 |
|---|---|---|
| 1 · 资质 | DSLV / BASI / N47 内训证书 | 教练上传 + 后台审核 |
| 2 · 经验 | "已上 142 节课" + 自己雪场打卡轨迹 | 自动累计 |
| 3 · 社交 | 学员真实评价 + 头像可点 | 平台撮合 / 老学员双标 |
| 4 · 响应 | 24h 回复率 | 自动统计 |

### 1.2 教练绕单的防御

| 行为 | 平台处理 |
|---|---|
| 学员看 Funwild 教练页 → 自己加微信绕单 | 无法阻止 |
| 学员从 Funwild 撮合 → 写评价 | 允许，且建议 |
| 学员从绕单 → 写评价 | **不允许**（限制写评价权限给"平台撮合"订单） |
| 教练把所有客户都从 wave 走 | 评价数据丰富 → 排序靠前 → 更多新客 |
| 教练把所有客户都绕单 | 评价数据稀少 → 排序靠后 → 失去新客 |

→ **不阻止绕单，但让绕单付出社交代价。**

### 1.3 教练入驻审核

| 字段 | 审核标准 |
|---|---|
| 证书照 | 真实 DSLV/BASI/N47 证书，号码可查 |
| 头像 | 真人雪场场景照，不是头像贴纸 |
| 自我介绍 | 不含夸张承诺（"100% 上瘾"等） |
| 价格 | 合理区间（€40-€200/h） |

不达标 → 拒绝入驻 + 反馈具体原因 + 鼓励重新申请。

## 2. 地接信任体系

### 2.1 信任信号

| 信号 | 实现 |
|---|---|
| "已成团 N 次" | 上传真实合影才解锁此数字 |
| 老客户评价 | 团结束后 14 天才开放评价（避免热情期高估） |
| 服务商个人主页 | 在欧居留 X 年 + 已办团数 |
| 取消政策 | 在项目页透明展示 |
| 紧急联系人 | 24h 待命，电话明示 |

### 2.2 防虚假信息

| 风险 | 防御 |
|---|---|
| 服务商发布不存在的项目 | 项目发布 24h 内人工审核 |
| 抄袭其他地接项目 | 抽查 + 用户举报 → 下架 |
| 价格欺骗 | "已成团"价格快照 + 用户评价中提价格 |
| 跑路 / 没履约 | Year 1 转介佣金浮动制 + 评价数据公开 |

### 2.3 地接入驻审核

不要求必须有公司 + 不要求实名，但需：
- 在欧洲有居留（提供居留卡照片）
- 有实际滑雪 / 户外经验（说明 + 历史照片）
- 提供 2 份老客户联系方式（平台可联系核实）

→ 详见 BP V7 § 2.2.5。

## 3. 用户信任 · 信用分（拼车）

### 3.1 信用分规则（详见 part_06_page_ux/09_carpool.md）

| 行为 | 分数变化 |
|---|---|
| 准时成行 | +2 |
| 24h 前取消 | +0 |
| 24h 内取消 | -2 |
| 缺席无通知 | -5 |
| 收到表扬 | +1 |
| 收到投诉 | -3 |

### 3.2 信用分用途

- 90+ → "诚信雪友"徽章 + 列表优先
- 70-90 → 普通
- < 70 → 不能发起拼车，只能加入
- < 50 → 进入低信用名单（发起人 warning 显示）

### 3.3 防恶意打分

- 发起人**不能**给申请者打"投诉"（避免恶意打分）
- 投诉需要双方都标"成行"才允许
- 每月信用分恢复 +5（鼓励重新建立信任）

## 4. 市集风险防御

### 4.1 防诈骗

| 风险 | 防御 |
|---|---|
| 假货 / 描述不符 | "建议当面验货付款"警示置顶 + 平台不参与交易 |
| 价格欺诈 | 价格字段必填 + 自动比对市场价 |
| 微信号 / 电话欺诈 | 描述里自动过滤微信号 / 手机号字符串 |
| 多次骗 | 三次被举报 → 帖子下架 + 限制发布 |

### 4.2 GDPR 友好

- 不存储用户的支付 / 银行信息（线下交易）
- 用户可一键删除发布的市集帖子
- 帖子保留 30 天后自动归档

## 5. 拼车安全（性骚扰 / 安全风险）

### 5.1 防护机制

- **Wave 机制**：双向意向才打开微信，单向 wave 不暴露
- **集合点延迟显示**：双方加入拼车后才显示，避免单方"埋伏"
- **任一方可取消**：任何时刻都可取消 + 不影响信用分（24h 前）
- **投诉冻结**：投诉对方 → 平台 24h 内冻结对方账号 + 调查

### 5.2 雪场内安全

- 紧急联系卡（每次行程前 push）
- 雪场救援电话清单（每个雪场页面有）
- "出意外了"求助入口（V1.1 我的"紧急求助"按钮）

## 6. 内容审核 · 评价系统

### 6.1 评价审核流程

```
用户写评价
  ↓
关键词过滤（脏话 / 微信号 / 电话）
  ↓
自动过滤 → 弹层"内容包含敏感词，请修改"
  ↓
未过滤的评价直接发布
  ↓
被举报后 → 人工审核 → 下架 / 保留
```

### 6.2 用户举报

任何用户可举报：
- 评价 / 攻略 / 市集帖子 / 教练页 / 地接页
- 举报后 24h 内人工审核（贺安祺）
- 三次举报同一内容 → 自动下架 + 通知发布者

## 7. N47 资格混淆风险

### 7.1 红线

BP V7 § 2.4 已明确：
- N47 的钱不能流向 Funwild / B-kuh 股东
- 不能把商业行为故意包装成 Zweckbetrieb

### 7.2 IA 层面防混淆

- 商业地接和体育推广团**在 IA 里完全分开**

About 页 → N47 介绍 → 解释 N47 是 gemeinnütziger Verein
让用户理解 N47 ⭐ 标签的含义。

## 8. GDPR 合规

### 8.1 数据收集最小化

| 数据 | 何时收集 | 用途 |
|---|---|---|
| 微信 openid + 昵称 + 头像 | onboarding | 登录 |
| 城市（粗粒度） | onboarding | 推荐 |
| 运动偏好 | onboarding | 推荐 |
| 真实姓名 | 报名活动时 | 安全 + 保险 |
| 手机号 | 报名活动时 | 紧急联系 |
| 位置（GPS） | 打卡时一次性 | 打卡 |

### 8.2 用户权利

- 查看自己的全部数据（"我的 → 设置 → 数据下载"）
- 删除账号（"我的 → 设置 → 删除账号"，30 天可恢复）
- 修改 / 撤回 同意（每次位置授权独立）
- 数据导出（JSON 格式）

### 8.3 数据存储

- 服务器位置：欧盟内（Frankfurt / Dublin）
- 加密：数据库 + 传输 TLS
- 不存储信用卡 / 银行卡信息
- 日志保留 90 天

### 8.4 第三方数据共享

| 第三方 | 数据 | 目的 |
|---|---|---|
| 微信（腾讯） | openid + 昵称 + 头像 | 登录 |
| 第三方分析（Mixpanel） | 匿名行为数据 | 产品分析 |
| 第三方雪况 API | 雪场名 + 经纬度 | 雪况查询 |

**不共享**：手机号 / 真实姓名 / 私信内容 / 评价内容 / 位置历史。

### 8.5 隐私政策页面

`funwild.com/about/legal/privacy/`
- 数据收集明细
- 用户权利
- 联系方式（隐私官 email）
- 最近更新时间

### 9.1 微信小程序审核要求

详见 [part_10_wechat_constraints.md](./part_10_wechat_constraints.md)。

## 10. 风险事件预案

### 10.1 事件类型与响应

| 事件 | 响应时间 | 处理 |
|---|---|---|
| 用户举报教练 / 地接 | 24h | 暂停 + 调查 |
| 性骚扰投诉 | 4h | 冻结对方 + 公安咨询 |
| 雪场意外（受伤） | 立即 | 联系教练 / 地接 / 紧急联系人 |
| 评价被刷（恶意 1 星） | 24h | 调查 + 暂时下架对应评价 |
| 微信封禁 / 警告 | 立即 | 团队会议 + 整改 |
| 数据泄露 | 立即 | 通知用户 + GDPR 上报 |

### 10.2 客服 SLA

- Year 1 客服：1 人（贺安祺）
- 工作时间：欧洲 9:00-18:00（CET）
- 非工作时间：晚上 / 周末由何柏岚 / 磊子 backup
- 紧急事件（性骚扰 / 意外）：4h 内响应

## 11. 用户协议要点

完整协议在 `funwild.com/about/legal/terms/`，核心：

1. Funwild **不参与交易**，不承担教练 / 地接 / 市集纠纷的赔偿责任
2. 用户**自行确认**教练 / 地接的资质 + 价格 + 服务范围
3. 评价 / 攻略 / 头像 / 昵称用户拥有版权，但授权 Funwild 平台展示
4. Funwild 有权下架违规内容 + 封禁违规用户
5. 用户对发布的内容**完全负责**（涉及版权 / 名誉权 / 隐私权 等）
