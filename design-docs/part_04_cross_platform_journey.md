# Part 4 · 跨平台用户旅程 · Cross-platform User Journey

> 3 条主 journey 的逐步拆解。每个 CTA 配状态地图 + drop-off 估计 + 干预方案。

---

## 0. Journey 定义

一条 journey = 一个用户类型从**首次接触**到**完成核心 conversion** 再到**第 N 次回访**的完整链路。

**Year 1 三条主 journey：**
- **Journey A · 国内游客**（小红书 → Website → 小程序 → 行后 UGC）
- **Journey B · 本地华人雪友**（N47 群 → 小程序 → 长期 retention）
- **Journey C · 教练入驻**（认识谁 → 入驻 → 接单 → 长期）

下面每条 journey 拆 14-18 步。每步描述：
- **入口**：用户在哪
- **看到什么**：UI 内容
- **用户会想什么**：心理状态
- **点击什么**：CTA
- **下一步触发什么**：系统反应
- **drop-off 估计**：流失百分比
- **干预**：降低流失的设计

## 1. Journey A · 国内游客 18 步

> Persona: 2B 年轻自由行 · 上海 · 25 岁 · 12 月计划去欧洲滑雪 7 天

### Step 1 · 小红书种草
- **入口**：小红书 App，刷"欧洲滑雪"标签
- **看到**：博主写的"欧洲 7 天滑雪攻略 #趣野Funwild"笔记，附 Funwild 短链
- **想什么**：哇这个 Stubaier 看起来超棒 + 我要看完整攻略
- **点击**：笔记里的短链
- **下一步**：跳转到浏览器，打开 Website `funwild.com/resort/austria/stubaier-gletscher/`
- **drop-off**：N/A（不是 Funwild 控制）
- **干预**：N/A

### Step 2 · Website 第一次访问
- **入口**：浏览器，Funwild Website Stubaier 攻略页
- **看到**：Hero 大图（雪山日出）+ "Stubaier Gletscher · 奥地利 · 冰川 + 公园" + 元数据卡（车程 / 海拔 / 雪季 / 难度分布）+ ❗ 特别提醒（停车场 9 点满 / 缆车排队 30 分钟）
- **想什么**：这个攻略看起来够专业 + 嗯 ❗ 提醒挺有用
- **点击**：往下滚
- **下一步**：渐进式 reveal 内容（怎么去 / 新手一日动线 / 进阶推荐 / 实用贴士）
- **drop-off**：35%（5 屏滚完只剩 65%）
- **干预**：第 2 屏插入"⏱ 预计 8 分钟读完，存到微信稍后看？"+ 二维码

### Step 3 · Website 停留 8 分钟，决定收藏
- **入口**：Stubaier 攻略页第 3 屏
- **看到**：右侧浮动卡片"⊕ 加入收藏 → 扫码同步到小程序"
- **想什么**：嗯收藏一下，不要每次重新找
- **点击**：扫码
- **下一步**：扫码后浏览器跳出"已加入收藏，可在微信小程序查看"+ deep link 携带 attraction_id
- **drop-off**：60%（多数用户不扫，先关闭）
- **干预**：扫码不强制登录，只是落 device id 做匿名映射

### Step 4 · 1 周后 Google 搜索，再次进入
- **入口**：Google "Stubaier 中文攻略"
- **看到**：Funwild Website 排第 1（SEO 资产）
- **想什么**：哦上次看过这个，再点一次
- **点击**：搜索结果
- **下一步**：Website 攻略页打开，Cookie 识别"这是回访用户"，顶部 banner"欢迎回来，上次看到第 X 段"
- **drop-off**：N/A
- **干预**：回访用户体验比首访好，建立"回家"感

### Step 5 · 比较 3 个教练
- **入口**：Stubaier 攻略页"教练联动"模块
- **看到**：3 个教练卡片（头像 / 名字 / 语言 / 价格 / 评价星级）
- **想什么**：哪个比较好？让我看看每个的页
- **点击**：第一个教练
- **下一步**：跳转到 `funwild.com/coach/zhang-lei/` 教练详情页
- **drop-off**：N/A
- **干预**：教练卡片信息密度要足够（不只是头像名字），用户才有动机点击

### Step 6 · 教练页深度浏览
- **入口**：教练 张磊 详情页
- **看到**：头像 + 名字 + 资质（DSLV Level 3）+ 语言（中/德/英）+ 价格（€60-90/h）+ 已上 142 节课 + 学员评价 38 条（含具体语句"第一次单板..."）
- **想什么**：这个教练 OK + 评价里有和我一样的新手，靠谱
- **点击**：底部"扫码联系（在小程序内）"按钮
- **下一步**：扫码 → 微信打开小程序 → 教练 张磊 详情页
- **drop-off**：50%（一半用户会先看其他教练再决定）
- **干预**：教练页右侧固定 CTA "扫码联系"，3 个教练共享同一个 modal pattern

### Step 7 · 小程序首次访问 + 一键登录
- **入口**：小程序"教练 张磊"页（从 Website 扫码跳转）
- **看到**：教练页 + 顶部小字"通过 Website 跳转，已为你打开张磊的页面"
- **想什么**：欸我没注册啊 + 不管，直接登录
- **点击**："发起 Wave"按钮
- **下一步**：弹微信授权 → 一键登录 → 进入 onboarding（2 步）
- **drop-off**：15%（少数用户对微信授权迟疑）
- **干预**：授权弹窗前显示"我们只需要你的昵称和头像，不会获取任何其他信息"

### Step 8 · Onboarding 2 步
- **入口**：onboarding step 1
- **看到**："你滑哪种？" [单板] [双板] [都滑] [不知道]
- **点击**：双板
- **下一步**：step 2 "你在欧洲哪里？" → 选"国内来玩" → 完成
- **drop-off**：8%（极少数）
- **干预**：可跳过（"先逛逛再说"按钮）

### Step 9 · 解锁趣野新人徽章
- **入口**：onboarding 完成
- **看到**：徽章动画弹窗 "趣野新人 ⭐ 解锁！" + 下一步徽章预告"还差 1 步解锁'首次出发'"
- **想什么**：哇徽章 + 心理印记建立
- **点击**：[继续] 进入小程序首页
- **下一步**：首页加载，hero 区显示"📍 你正在看 Stubaier，要做什么？"+ 3 个大按钮
- **drop-off**：N/A
- **干预**：首屏直接对接 Step 6 的意图（看 Stubaier 教练）

### Step 10 · 发起 Wave
- **入口**：教练 张磊 详情页
- **看到**：底部 "[发起 Wave →]  [⏱ 24h 内回复率 95%]"
- **想什么**：试试看
- **点击**：发起 Wave
- **下一步**：弹层"给张磊发起 wave，他会在 24h 内回复" + 默认消息 "你好，我对你的课程感兴趣" + 用户可修改 + 确认发送
- **drop-off**：30%（用户怕被骚扰 / 不知道发什么）
- **干预**：默认消息模板降低写作 friction

### Step 11 · 张磊回 Wave + 微信对话框打开
- **入口**：发 wave 后 5 分钟，张磊在小程序看到通知，点回 wave
- **用户接收端**：小程序消息中心"张磊回了你的 wave"+ "打开微信对话框联系"按钮
- **想什么**：靠谱 + 这就联系上了
- **点击**：打开微信对话框
- **下一步**：微信打开张磊的对话框 + 系统自动发了一条消息"我对你的课程感兴趣，看了你的资料 / 评价 / 行程"
- **drop-off**：5%（极少）
- **干预**：自动消息让用户不用打第一句

### Step 12 · 行前规划 + 报名活动
- **入口**：1 周后用户在小程序"探索 → 活动"
- **看到**：Stubaier 区域活动列表 + "Camp Good Times 2026 · 12-15 Dec"（恰好在用户行程内）
- **想什么**：哇正好 4 天滑雪营，我去看看
- **点击**：活动详情
- **下一步**：进入活动详情页（详见 [part_06_page_ux/06_activity_detail.md](./part_06_page_ux/06_activity_detail.md)）
- **drop-off**：N/A
- **干预**：N/A

### Step 13 · 占位报名
- **入口**：活动详情页底部固定 CTA "立即报名"
- **看到**：报名表单（姓名 / 联系方式 / 是否带朋友 / 备注）
- **想什么**：报上再说，不付款不浪费
- **点击**：占位
- **下一步**：占位成功 + "客服会在 24h 内联系收款" + 自动加入"我的活动"
- **drop-off**：40%（一半用户犹豫不报）
- **干预**：占位免费 + 24h 不付款自动释放 + 显示"剩余 X 个名额"

### Step 14 · 行前 7 天 push
- **入口**：行前 7 天，订阅消息触发
- **看到**：服务号消息"距离 Stubaier 之旅还有 7 天 ❄ 行李清单 + 离线 PDF 攻略 + 紧急联系卡"
- **想什么**：哇好贴心
- **点击**：进入小程序"我的行程"
- **下一步**：看到 checklist + 一键发送 PDF 到微信
- **drop-off**：N/A
- **干预**：N/A

### Step 15 · 行中第 1 天打卡
- **入口**：到达 Stubaier 当天，小程序首页
- **看到**：Hero "📍 你在 Stubaier 5km 内 → 打卡？"
- **想什么**：来都来了 + 打卡好玩
- **点击**：打卡
- **下一步**：wx.getLocation 授权 → 打卡成功 → 解锁"欧洲首次打卡"徽章 → 海报自动生成
- **drop-off**：20%（部分用户对位置授权犹豫）
- **干预**：授权前展示"打卡只需要一次位置，不会持续追踪"

### Step 16 · 海报分享
- **入口**：徽章解锁弹窗
- **看到**：海报预览（雪山背景 + 头像 + 徽章 + Funwild 二维码）+ "保存到相册" / "分享到朋友圈"
- **想什么**：好看，发！
- **点击**：分享到朋友圈
- **下一步**：保存图片 + 打开朋友圈
- **drop-off**：50%（一半用户保存了但不发）
- **干预**：海报视觉天花板必须高（设计师产能投入）

### Step 17 · 行后评价 + 写攻略
- **入口**：行后第 7 天，订阅消息触发
- **看到**：服务号消息"评价张磊教练，可解锁'攻略救了我'徽章 + 把这次旅行写成攻略可得 3 个徽章"
- **想什么**：可以可以
- **点击**：评价教练
- **下一步**：评价完成 → 弹"写攻略可得 X 徽章 + 这是模板" → 用户用模板写
- **drop-off**：60%（写评价 40%）+ 80%（写攻略 20%）
- **干预**：模板大幅降低写作 friction

### Step 18 · UGC 同步小红书 + 触发下一波
- **入口**：用户写完攻略，小程序"我的攻略"
- **看到**："已发布！同步到小红书可获得'小红书种草官'徽章"+ 一键复制内容到小红书 App
- **想什么**：可以
- **点击**：复制到小红书
- **下一步**：在小红书发笔记 → 笔记带 #趣野Funwild 标签 → 触发 Step 1 next 用户
- **drop-off**：50%
- **干预**：复制时自动加 hashtag 和 mention，用户不用想

| 节点 | 累积存留 |
|---|---|
| Step 1 看到 | 100% |
| Step 2 进 Website | 100% |
| Step 4 SEO 回访 | 50% |
| Step 7 进小程序 | 25% |

## 3. Journey C · 教练入驻 14 步

> Persona: 3A 职业教练 · 慕尼黑 · 35 岁 · DSLV Level 3 · 单板 · 雪季全职

### Step 1 · 朋友介绍 / 看到入驻广告
- **入口**：N47 群 / 微信公众号 / 朋友推荐
- **看到**：磊子 / 詹敏杰 发的"Funwild 教练入驻 · 首批 5-10 个免费 · 个人页 + 评价 + N47 学员"
- **想什么**：试试看，反正免费
- **点击**：扫码 / 留言

### Step 2 · 磊子 1v1 沟通
- **入口**：微信加好友
- **磊子**：介绍 Funwild、教练页 demo、收益预期
- **教练问**：抽佣？规则？工作量？
- **磊子答**：年费 €99（首批免费）+ 不抽佣 + 工作量低
- **drop-off**：30%（教练嫌麻烦）
- **干预**：磊子提供 demo 截图 + 已入驻教练背书

### Step 3 · 教练同意入驻
- **入口**：磊子发"教练入驻链接 + 资料清单"
- **教练**：准备资料（证书照、自拍、自我介绍）
- **下一步**：磊子代教练录入或教练自主提交
- **drop-off**：10%
- **干预**：磊子代录入，降低教练 friction

### Step 4 · 后台审核
- **入口**：Funwild 后台
- **审核人**：何柏岚 / 贺安祺
- **审核内容**：证书真实性 + 资料完整性 + 头像是否专业
- **drop-off**：5%
- **干预**：审核 < 24h

### Step 5 · 教练页上线
- **入口**：审核通过
- **教练收到**：微信通知"你的 Funwild 个人页已上线 + 网址 / 二维码"
- **教练**：第一次点开自己页面，看到"DSLV Level 3 · €60-90 / 小时 · 已上 0 节课"
- **想什么**：哎好像没什么内容啊
- **干预**：提供"上线 starter pack"——5 张专业雪场照 + 学员评价模板（让教练联系老学员补 3-5 条历史评价）

### Step 6 · 教练首次发布"本周行程"
- **入口**：教练后台"行程发布"
- **看到**：简洁表单 "下周哪天 + 哪个雪场 + 有空时间段 + 备注"
- **想什么**：试一下
- **点击**：[发布]
- **drop-off**：50%（兼职教练不主动维护）
- **干预**：每周日晚 push 提醒"发布你的本周行程"

### Step 7 · 教练收到第一个 wave
- **入口**：5 天后，教练在小程序消息中心
- **看到**："Y 发起了 wave + Y 的个人主页 + 默认消息"
- **想什么**：哇真的有人联系
- **点击**：[回 wave]
- **drop-off**：N/A
- **干预**：教练后台高亮"X 个待回 wave"

### Step 8 · 双方微信对话
- **入口**：回 wave 后微信对话框打开
- **教练**：发"你好，我看了你的资料，建议..."
- **学员**：回复，进入价格 / 时间确认
- **drop-off**：60%（一半 wave 不成单）
- **干预**：教练的 24h 回复率影响列表排序，激励教练快速回复

### Step 9 · 成单 + 线下上课
- **入口**：1-2 周后，约定时间
- **教练**：在雪场和学员见面 + 上课 + 自己收款（线下转账）
- **drop-off**：5%
- **干预**：教练 / 学员任一方临时取消的"信用分"系统

### Step 10 · 上课后 push 学员评价
- **入口**：上课后第 1 天，订阅消息
- **学员看到**："评价张磊教练，可解锁'攻略救了我'徽章"
- **drop-off**：60%
- **干预**：评价表单 1 分钟内完成（5 星 + 1 句话）

### Step 11 · 教练看到评价 + 更新教练页
- **入口**：教练在后台
- **看到**："你收到了新评价 + 评价已上线到你的页面"
- **想什么**：感谢平台，越来越像样
- **drop-off**：N/A
- **干预**：评价上线弹通知"你的总评分从 4.8 → 4.85"

### Step 12 · 教练分享教练页给朋友 / 学员
- **入口**：教练页右上角分享
- **教练**：把自己的页面分享到朋友圈 / 群
- **效果**：朋友圈外人扫码进小程序 → 看到教练页 → 注册
- **drop-off**：N/A
- **干预**：教练页 SEO + 海报模板（"我是 Funwild 认证教练"）

### Step 13 · 雪季内重复 6-9 → 累计接单
- 教练每周发行程 → 收 wave → 成单
- 平均每月接 5-10 单
- 累计评价 30+ 后进入"明星教练·金"徽章

### Step 14 · 雪季后续约 / 老学员回购
- **雪季结束**：教练收到雪季总结 "本雪季接单 X 次 + 收入 €Y + Z 个学员关注你"
- **下个雪季**：老学员通过关注列表看到教练新行程，直接联系
- **drop-off**：N/A
- **干预**：关注列表是教练的"私域"，平台不打扰

### Journey C 关键指标
- 入驻完成率：60%（Step 1-5 通过率）
- 雪季内活跃率：50%（Step 6 持续发布行程）
- 平均月接单：5-10 单
- 老学员回购率：30%

## 4. 跨 Journey 共享的关键 trigger

下面这些 trigger 在多条 journey 中重复出现，必须**集中规划**而不是逐 journey 单独设计。

### 4.1 ⭐ 周三晚 8 点 push
- 内容："本周末雪友动态 · X 人计划去 Y"
- 触发：定时 cron job + 个性化
- 重要性：**Year 1 retention 核心**

### 4.2 行前 7 天 push
- 内容：行李清单 + PDF 攻略 + 紧急联系卡
- 触发：用户报名 / 占位活动后

### 4.3 雪场 5km 内 hero 变化
- 内容：首页 hero 自动切换为"📍 你在 X 5km 内 → 打卡？"
- 触发：wx.getLocation 一次性
- 重要性：**core retention loop**

### 4.4 徽章解锁动画 + 海报生成
- 时机：任何 action 触发徽章
- 重要性：**viral growth 引擎**

### 4.5 行后 7 天 push 评价 + 写攻略
- 触发：活动 / 教练 / 地接订单完成 7 天后
- 重要性：**UGC 反哺 + retention 二次**

### 4.6 1 周后系统推关注
- 内容："你和 X 一起去过 Y，互相关注吗？"
- 触发：拼车成行 / 同活动 7 天后
- 重要性：**网络效应建立**
