# ★ Onboarding · 新手引导

> activation-critical · < 30 秒完成率 ≥ 75% · 首次徽章解锁

---

## 既有资产 / 修改方向 / 新增内容

- **既有资产**：无 onboarding mockup。
- **新增**：6 步全新流程，每步只问一个事 + 直接给反馈 + 第 6 步解锁第一枚徽章。

---

## 页面目标

让用户 **30 秒内**从打开小程序到看到首页 + 解锁第一枚徽章。

## 用户心理

- "这又要填一堆表"
- "微信登录会泄露什么信息"
- "我能直接逛吗"

→ 全部解法：**只问 2 个事**，其余字段后续场景按需收集。

---

## 6 步流程

### Step 1 · 微信一键登录（无 UI 介入）

```
用户打开小程序
  ↓
小程序自动调用 wx.login()
  ↓
弹微信原生授权框
  "趣野 Funwild 想要获取你的头像、昵称"
  [允许]  [拒绝]
```

**关键判断**：
- 不显示"为什么需要授权"前置说明（增加 friction）
- 用户拒绝时弹"必须授权才能继续，[再试一次] [先逛逛]"
- "先逛逛"进入未登录态，所有写操作都触发登录

### Step 2 · 欢迎屏（5 秒动画）

```
┌─────────────────────────────────────┐
│                                     │
│         [Funwild Logo 大]           │ ← 大 Logo 动画
│                                     │
│         你好 张小美                  │ ← 微信头像 + 昵称
│                                     │
│   我们想了解你 2 件事就放你进来        │
│                                     │
│              [跳过 →]                │ ← 右下小字
│                                     │
└─────────────────────────────────────┘
```

**关键判断**：
- "2 件事"明确预期，降低用户对长 onboarding 的恐惧
- "跳过"按钮存在但不显眼，让用户知道可以跳过

### Step 3 · 问题 1 · 你滑哪种？

```
┌─────────────────────────────────────┐
│ 1 / 2                               │ ← 进度
├─────────────────────────────────────┤
│                                     │
│         你滑哪种？                   │
│                                     │
│   ╭───────╮  ╭───────╮              │
│   │  🏂   │  │  ⛷   │              │
│   │ 单板   │  │  双板  │             │ ← 大卡片选项
│   ╰───────╯  ╰───────╯              │
│                                     │
│   ╭───────╮  ╭───────╮              │
│   │  🌟    │  │  ❓   │              │
│   │ 都滑   │  │ 还不知  │             │
│   ╰───────╯  ╰───────╯              │
│                                     │
│              [跳过 →]                │
│                                     │
└─────────────────────────────────────┘
```

**关键判断**：
- 大卡片 + emoji 比文字单选 + radio 更友好（情绪化）
- 默认接受"还不知道"（新手友好）
- 选完自动进入 Step 4（不需要"下一步"按钮）

```

├─────────────────────────────────────┤
│                                     │
│         你在欧洲哪里？               │
│                                     │

```

**关键判断**：
- 6 个选项覆盖 95% 用户
- "国内来欧洲玩" 路由到**类型 2 体验**（不同首页 / 推荐 / 文案）
- 选 "其他" 后续可详细填

### Step 5 · 解锁第一枚徽章

```
┌─────────────────────────────────────┐
│                                     │
│            [大徽章动画]               │ ← spring 480ms 弹入
│                                     │
│           ⭐ 趣野新人                 │
│                                     │
│   恭喜！你解锁了第一枚徽章            │
│                                     │
│   ─── 还差 1 步 ────                │
│   解锁 "首次出发"                    │
│   下一次去任何雪场打卡即可解锁         │
│                                     │
│        [太棒了 →]                    │ ← Primary CTA
│        [分享给朋友 ⤴]                │ ← Secondary CTA
│                                     │
└─────────────────────────────────────┘
```

**关键判断**：
- 第一枚徽章必须**立刻可见 + 名字明确 + 仪式感**
- 同时显示**下一枚徽章预告**，建立 retention loop
- "分享给朋友" 可选（不强制），不打断流程

### Step 6 · 进入首页 · spotlight 教程

```
┌─────────────────────────────────────┐
│ 9:41                          5G 87 │
├─────────────────────────────────────┤
│ 📍 慕尼黑 ▾              🔍  🔔(0)   │
├─────────────────────────────────────┤
│                                     │
│  本周末 5 位雪友计划去 Spitzingsee   │ ← spotlight + 高亮
│  [详情 →]                            │ ← 大 hint 箭头
│                                     │
│  ...（首页其他内容半透明）            │
│                                     │
├─────────────────────────────────────┤
│  首页  出行  探索  消息  我的         │
└─────────────────────────────────────┘
```

**关键判断**：
- 只给 1 个 spotlight，不要给 5 个（信息过载）
- 第一个 spotlight 必须**可执行**（"详情 →"）而不是"看看"
- 30 秒不点击自动消失 + 顶部 ribbon "需要帮助？看新手指南 →"

## States 矩阵

| 状态 | 行为 |
|---|---|
| **首次完成 onboarding** | 解锁徽章 + 进入首页 spotlight |
| **半路退出（< Step 5）** | 下次打开从未完成的 step 继续 |
| **完成 onboarding 后第 2 次打开** | 直接进入首页，无 spotlight |
| **微信授权拒绝** | "先逛逛" 模式 + 所有写操作 → 重新触发授权 |
| **跳过所有问题** | 用户进入首页，但 profile 信息缺失（hint 上方"完善资料解锁 1 个徽章"） |

---

## Trust Signals

- 微信授权弹窗：默认信任（微信原生 UI）
- "我们想了解你 2 件事就放你进来" 明确预期
- 进度条 "1 / 2" 让用户知道还有几步
- "跳过" 始终可见，给用户掌控感

---

## Micro-interactions

- Logo 出现：spring 480ms + 淡入
- 卡片选项选中：scale 1.05 + accent border + 自动 next
- 徽章解锁：spring 480ms + 粒子动画 + haptic feedback heavy
- Spotlight：背景半透明 + spring 进入 + 30s 自动关闭

---

## Loading / Empty / Error

- **Loading**：每步切换时 < 200ms，骨架可省
- **Error 微信授权失败**：弹层"重新授权" + "先逛逛" 二选一
- **Error 网络异常**：步骤数据存本地，恢复网络后同步

## 完成率优化

| 杠杆 | 影响 |
|---|---|
| 字段数 | 每多 1 个字段 -15% 完成率 → 只问 2 个 |
| 跳过按钮 | 显眼 → 跳过率高；隐藏 → 流失率高 → 不显眼但存在 |
| 徽章解锁 | 没有 → 完成感弱；有 → 完成率 +20% |
| 微信授权阻塞 | 强制 → 流失 30%；可选（先逛逛） → 流失 15% |
| 进度条 | 不显示 → 焦虑感强；显示"1/2" → 安心 |
| Step 5 分享 | 强制 → 反感；可选 → 自然分享 1-3% |

---

## 分享机制

- Step 5 "分享给朋友" 按钮 → 海报：用户头像 + "我加入了趣野" + Funwild 二维码
- 朋友点击二维码 → 进入小程序 + 自动归因（邀请人 +1 邀请徽章进度）

---

## Conversion Logic

| 完成率目标 | 75%（Year 1） |
|---|---|
| 微信授权同意 | 92% |
| Step 3 选择运动 | 95% × 92% = 87% |
| Step 4 选择地区 | 95% × 87% = 83% |
| 看徽章解锁 | 100% × 83% = 83% |
| 进入首页 spotlight | 90% × 83% = 75% |
| **完整完成 onboarding** | **75%** |

→ 任何额外字段（昵称 / 头像 / 真实姓名 / 手机号 / 滑雪水平 / 邀请码）都会拉低完成率，必须**禁止**在 onboarding 阶段增加。

## 后续渐进式收集 profile 信息

| 字段 | 何时收集 |
|---|---|
| 真实姓名 | 报名活动时（用于安全 + 保险） |
| 手机号 | 报名活动 / 联系客服时 |
| 滑雪水平 | 发拼车 / 找教练时（自动 hint 选） |
| 邀请码 | 设置页面 / 邀请记录 |
| 头像 | 用户自己想换时（微信头像默认 OK） |
| 个人简介 | 公开主页（V1.1） |

## Tokens 引用

- Logo 动画：`size = 120px → 80px shrink` after 3s
- 选项卡：`size = 140 × 100px`, `radius = radius-md`, `bg = surface.raised`, `border = bd.default`, selected `border = accent[600] · 2px`
- 进度文字：`text-micro · mono · letter-spacing 1.5 · uppercase`
- 徽章解锁 hero：`size = 200px`, glow `accent[500]` 30% opacity
- "还差 1 步" 文字：`text-body-sm · accent[700]`
- Primary CTA：`bg = accent[600]`, `radius = radius-sm`, `padding = space-3 space-8`
