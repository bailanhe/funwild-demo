## 筛选

| 维度 | 选项 |
|---|---|
| **语言** | 中文 / 中文+德文 / 中文+英文 |
| **雪场** | 18 个雪场多选 |
| **价格** | < €60/h / €60-90 / €90-120 / > €120 |
| **运动** | 单板 / 双板 / Ski Touring / Freeride |
| **类型** | 私课 / 小组课 / 训练营 |
| **特性** | 带过国内学员 / DSLV 认证 / 24h 高回复 |

## 排序

- 热门（默认）= 评价数 + 评分 + 回复率
- 回复率（高 → 低）
- 评分（高 → 低）
- 价格（低 → 高 / 高 → 低）
- 新入驻（< 30 天）

## States

| 状态 | 渲染 |
|---|---|
| 默认 | 显示已认证教练 |
| 筛选后 0 | "未找到匹配教练，[调整筛选] [发布找教练]" |
| 教练本周无空 | 卡片显示 "本周无可约" 灰态 |

## Trust Signals

- ⏱ 回复率 prominently displayed
- ★ 评分基于真实订单
- "带过国内学员" tag 对 2A 用户特别重要

## Conversion

- 列表点击进入详情页 → 发 wave
