### 占位 → 实际付款的转化率提升设计

- **不要把"立即付款"做成默认**：用户犹豫时只占位，降低决策成本
- **24h 倒计时显示**：制造紧迫感
- **24h 自动释放**：保证名额公平流转
- **客服私聊收款**：人工触达比自助支付转化率高

## Loading / Empty / Error

- **Loading**：骨架屏
- **Empty 0 报名**：进度条隐藏 + "成为第一位报名 · 等满 5 人后开团"
- **Error**：占位失败 → "请重试" / "已满，看看类似活动"

---

## Trust Signals

1. **主办方背书**：N47 ⭐ 金标 + 历史活动数
2. **已报名头像 + "认识的人也报了"**：社交认同
3. **取消政策透明**：FAQ 置顶
4. **常见疑问解答**：减少私聊咨询

---

## Micro-interactions

- 容量进度条：填充动画 ease 400ms（每次刷新时）
- 已报名头像滚动：水平 carousel auto-scroll（如果 > 10 人）
- 立即占位按钮按下：scale 0.96 + spring 弹层
- "你认识的 X 也报了"出现：从下 fade up + 200ms decel

## 分享机制

- 右上角 share → 海报：活动封面 + 名字 + 日期 + "趣野" 二维码 + "已报 X / Y 人"
- 分享文案默认："我报名了 Camp Good Times 2026 · 还差 12 位 · 一起 ❄"

## Conversion Logic

| 用户路径 | 决策依据 |
|---|---|
| 首页推荐 → 详情 | 看主办 + 价格 + 容量 → 占位 |
| 活动列表筛选 → 详情 | 看价格 + 日期 + 类似活动 → 占位 |
| 朋友分享海报 → 详情 | 看认识的人 → 占位 |
| 教练页推荐 → 详情 | 看主办教练 → 占位 |

## Tokens 引用

- 容量进度条：`bg = neutral[200]`, `fill = accent[500]`, `radius = full`, `height = 8px`
