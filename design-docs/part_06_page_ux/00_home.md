# 小程序首页 · Home

> Tab 1 · 小程序进入后第一屏 · 角色 = 意图分流器 + 动态流入口

---

## 既有资产 / 修改方向 / 新增内容

- **既有资产**：`brand_design/directions/03-mobile.jsx` 已有视觉级首页（SNOW REPORT 黑色 hero 卡片 + 4 quick actions + 雪场推荐 horizontal scroll + 近期活动）。**问题**：用了大陆雪场名（万龙 / 南山 / 张家口），逻辑是"内容展示橱窗"而不是 BP S6 要求的"意图分流器"。
- **修改方向**：保留 SNOW REPORT 卡片视觉 + 4 quick actions 排版；替换内容为欧洲雪场 + 重组结构为"我的进行中 + 关注的人动态 + 一个推荐位"。
- **新增**：动态 hero 切换逻辑（雪场内 / 行程内 / 默认 3 态）+ 关注的人动态流 + loading / empty / error 状态。

---

## 页面目标

让用户在**3 秒内**找到下一步该做的事。

## 用户目标

| 用户类型 | 来这看什么 |
|---|---|
| 1A Hardcore | 今天 / 这周末雪况 + 同级别雪友轨迹 |
| 1B 周末玩家 | 周末谁去哪雪场 + 我的徽章进度 |
| 1C 新手 | 新手该看什么 + 教练入口 |
| 1D 社交型 | 我的徽章进度 + 关注的人动态 |
| 2A-D 国内游客 | 我的行程倒计时 + 客服入口 |

→ 同一首页**根据用户类型 + 当前状态**动态渲染。

## Primary / Secondary CTA

- **Primary**：Hero 卡片的动作（雪场内 = 打卡 / 行程内 = 查看清单 / 默认 = 看雪场推荐）
- **Secondary**：4 Quick Actions（雪场 / 教练 / 活动 / 攻略）

---

## States 矩阵

| 状态 | 渲染 |
|---|---|
| **未登录** | 整页可见，但所有 CTA 触发微信一键登录 |
| **首次登录 onboarding 完成** | 一个 spotlight 教程指向 4 quick actions |
| **雪场 5km 内** | Hero = "📍 你在 X，要打卡？" + 大打卡按钮 |
| **行程进行中** | Hero = "📅 距离 X 还有 N 天" + 行前清单 |
| **关注的人有动态** | "本周末雪友动态" 模块显示 |
| **无关注的人 / 新用户** | "本周末雪友动态" 显示 3 条系统推荐 |
| **雪季外（5-10 月）** | Hero = "夏天的冰川也很美" + 切换到 ski touring / 冰川滑雪推荐 |
| **网络异常** | 顶部 banner "网络不好，正在加载" + 缓存版本 |
| **数据加载中** | 骨架屏（各模块灰色占位） |

## Trust Signals

- 雪场实时雪况数据（Year 1 接第三方 / Year 2 自建）
- 拼车发起人公开主页可点
- 徽章进度条让"差 1 步"可见

---

## Micro-interactions

- 进入页面：从下往上 80ms decel ease
- Hero 卡片切换：crossfade 200ms
- 打卡按钮按下：scale 1.05 + haptic feedback
- 红点未读：呼吸动画 1.2s spring loop

---

## 分享机制

- 顶部右上 share 按钮 → 生成"我推荐 Funwild"海报 + 二维码 + 个人徽章

---

## Conversion Logic

| 状态 | 期望下一步动作 |
|---|---|
| 新用户 | 点 4 Quick Actions 之一探索 |
| 老用户雪季内 | 看到拼车 / 行程 / 徽章 → 进一步 |
| 雪场内 | 打卡 |
| 雪季外 | 看徽章年度回顾 / 看 ski touring |

## Conflict Notes

- **与 brand_design 现有 mockup 的偏差**：原版用 4 quick actions（雪场 / 教练 / 活动 / 攻略），保留；但首屏内容从"雪场推荐 + 近期活动"改为"我的进行中 + 本周末雪友动态"，更贴合"意图分流器"定位。
- **与 BP V7 偏差**：BP § 2.1.3 首页有"会员预告位 + N47 合作伙伴入口 + 热门活动/地接推荐 + B-kuh 推荐"。本规格简化首页，把这些挤出首屏，放进对应板块。

## Tokens 引用

- Hero 黑色卡片：`bg = neutral[900]`, `text = white`, `padding = space-4 + space-3`
- Quick action 圆角方形：`radius = radius-xl (12)`, `size = 44px`, `bg = accent[50]`（首项）/ `neutral[100]`（其他）
- 数字（雪深 / 温度）：`Geist Mono · tabular-nums · weight 500`
