## 消息类型

| 类型 | 子类型 |
|---|---|
| **系统通知** | 徽章解锁 / 拼车提醒 / 周三晚推送 / 行程提醒 |
| **Wave** | 教练 / 拼车伙伴对你 wave 反馈 |
| **申请** | 拼车申请 / 活动审批（V1.1） |
| **对话** | 教练 / 地接 微信对话框入口（V1.1 私信） |

## 消息行为

- **可标记**：长按 → 标记已读 / 删除 / 取消订阅
- **可批量**：右上"全部已读"
- **过期**：超过 30 天自动归档（用户可查看历史）

## States

| 状态 | 渲染 |
|---|---|
| 0 消息 | "暂无消息，开始你的雪季吧" + 推荐 action |
| 全部已读 | 灰色 list |
| 有未读 | 红点显示 + 顶部 tab bar 显示数字 |

## 优先级排序

1. 需要立即处理的（wave / 申请）
2. 时效性（行程提醒 / 周三推送）
3. 完成感（徽章解锁）
4. 信息性（系统通知）

## 微信服务号兜底

- 同一消息同时推到微信服务号（如果用户已关注）
- 用户在小程序内看了 → 微信服务号自动标已读
- 用户在微信服务号点击 → 跳回小程序

## Tokens

- 消息卡：`bg = surface.raised`, `padding = space-3 space-4`, `radius = radius-sm`
- 未读红点：`bg = danger.solid`, `size = 8px`, `radius = full`
- Wave 卡片：左侧 accent strip `accent[600]` 3px
- 时间戳：`text-micro · mono · neutral.faint`
