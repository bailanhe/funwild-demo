## CTA

- Primary：「立即咨询 →」→ 跳转地接的微信对话框（不接管对话）
- Secondary：[收藏] [分享]

## States

| 状态 | 渲染 |
|---|---|
| 可咨询 | 立即咨询 + 服务商 24h 回复率 |
| 团已满 | "下团 X 月" + 候补名单 |
| 已结束季度 | "本季已结束，下个雪季再约" |
| 服务商 7 天未回应 | warning "回复较慢" |

## Trust Signals

- 已成团合影（真实，需上传解锁）
- 评价 + 老客户头像
- 取消政策透明
- 紧急联系人显示

## 防绕单 / 防抢客

- 所有 CTA → 服务商自己的微信，平台不接管
- 服务商焦虑被解决，所以愿意入驻
- 平台从转介佣金（BP § 2.3.3）获益

## Tokens

- 安全保障卡：`bg = semantic.info.bg`, `padding = space-4`
- 价格 hero：`Geist Mono · tabular-nums · text-h1`
- 已成团相册：grid 3-4 列 + 圆角 `radius-sm`
