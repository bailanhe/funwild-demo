# 全局搜索 · Search

> 任意页右上角搜索 icon 触发

---

## 页面目标

让用户在 **20 秒内**找到任何雪场 / 教练 / 活动 / 地接 / 用户 / 徽章。

## 用户心理

- "我记得有个 Stubaier 的雪场，但叫什么来着" → 模糊
- "我想找会中文的教练" → 关键词
- "Camp Good Times" → 具体名

## States

| 状态 | 渲染 |
|---|---|
| 空 query | 最近搜索 + 热门搜索 + 浏览推荐 |
| 输入中（< 3 字符） | 自动补全建议 |
| 输入后 0 结果 | "未找到匹配，[发布找教练] [发布出行] [问客服]" |
| 输入后有结果 | 分类聚合 + 每组显示前 3 |

## 自动补全

- 输入 "stu" → 弹出 "Stubaier Gletscher" "Stubai 谷"
- 输入 "中文" → 弹出 "中文教练" "中文地接"
- 输入 "周末" → 弹出 "本周末出行" "本周末活动"

## Year 1 实现

- 数据库 `LIKE '%query%'` 跨表查询
- 不做拼音 / 同义词 / 模糊匹配（Year 2 上 Algolia）
- Caching 热门关键词

## Tokens

- 搜索框：`bg = surface.sunken`, `radius = radius-sm`, `padding = space-3 space-4`
- 结果分类标题：`text-micro · mono · uppercase · letter-spacing 1.5`
- 结果 row：`padding = space-3 space-4`, hover `bg = sunken`
