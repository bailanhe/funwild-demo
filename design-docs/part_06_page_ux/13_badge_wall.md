## 页面目标

让用户在 **30 秒内**看到 "我已经收集了什么 + 还有什么可拿"。

## 用户心理

- "我都拿了哪些徽章" - 成就感回看
- "还差什么能拿" - retention nudge
- "这枚酷的我怎么没拿到" - 探索动机
- "晒朋友圈" - viral

## States 矩阵

| 状态 | 渲染 |
|---|---|
| **已解锁** | 彩色 + 名字 + tooltip 解锁日期 |
| **未解锁（可见）** | 灰态 + 名字 |
| **未解锁（隐藏）** | 灰 + "???" 名字隐藏 |
| **临近解锁（50-99%）** | 灰 + 进度环（环绕徽章 ring） + 显示进度 |
| **限时活动徽章** | 彩色 + "限时" 角标 + 倒计时 |
| **稀有徽章（< 1% 用户）** | 彩色 + "稀有" 角标 + glow 动画 |

## 徽章三态视觉设计（设计师补足）

```
已解锁    未解锁          50% 进度
[彩色]    [灰色]          [灰 + 环 50%]
 SVG        SVG             SVG + ring
1.0        0.4              0.4 + accent ring
```

**实现细节**：
- 灰态用 CSS `filter: grayscale(1) opacity(0.4)`
- 50% 进度用 SVG `stroke-dasharray` 环绕徽章
- 设计师不需要重做 142 SVG，CSS 即可派生灰 / 进度态

## Loading / Empty / Error

- **Loading**：骨架屏（大徽章占位 + 进度条占位）
- **Empty 新用户**：所有徽章灰色 + 1 个高亮"趣野新人" + 引导"完成 onboarding 解锁第一枚"
- **Error**：本地缓存版本 + 顶部 banner 提示

---

## Trust Signals

- "全平台 N 人解锁" 显示稀缺度
- 解锁者头像 list 可点（可看到 Hardcore 都解锁了什么）
- 徽章解锁日期不可篡改

---

## Micro-interactions

- 进入页面：徽章依次出现（stagger 50ms，from 第 1 到第 N）
- 点徽章：弹层从中心 zoom + spring（480ms）
- 主徽章切换：当前主徽章脱离飞回 grid + 新主徽章飞到 hero 位置
- 即将解锁卡片：呼吸动画 1.5s loop（弱）
- 进度环：从 0 到 N% 填充 800ms ease

---

## 主徽章选择

- 用户可选 1 个徽章作为"主徽章"
- 主徽章在个人主页 / 拼车卡片 / 评价等所有公开露出
- 主徽章可随时换
- 默认主徽章 = 最新解锁的有意义徽章（不是"趣野新人"）

---

## 即将解锁 Nudge 算法

排序优先级：
1. 差 1 步即可解锁（最强动机）
2. 进度 80%+ 的
3. 雪季内可达（周末玩家相关）
4. 当前位置相关（在雪场 5km 内的相关徽章）

每个 nudge 卡片必须配 1 个**可点击的下一步动作**：
- "拼车发起人 · 差 1 次" → [发布出行]
- "阿尔卑斯三国 · 差意大利" → [看意大利雪场]
- "打卡 30 次 · 差 8 次" → [本周末出行]

## Conversion Logic

| 用户路径 | 决策依据 |
|---|---|
| 看徽章墙 → 看到差 1 步 → 发拼车 | 即将解锁的可执行 nudge |
| 看徽章墙 → 看到隐藏 → 探索 | 神秘徽章激发好奇 |
| 看徽章墙 → 分享朋友圈 | 视觉好看 + 成就晒 |
| 朋友圈 → 朋友看到 → 扫码下载 | viral growth |

## Tokens 引用

- 大徽章 hero：`size = 80px`, `主徽章 size = 120px`
- Grid：`columns = 4`, `gap = space-3`, `padding = space-4`
- 进度条：`bg = neutral[200]`, `fill = accent[500]`, `height = 8px`, `radius = full`
- "即将解锁" 卡：`bg = accent[50]`, `border-left = 3px accent[600]`, `padding = space-4`
- 隐藏徽章 "?"：`color = neutral.faint`, `text-h1`, mono
- 海报背景：雪场真实照片 + 50% 暗化 overlay
