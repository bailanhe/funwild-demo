# ★ 雪场详情页 · Resort Detail

> conversion-critical · 决定用户"来 / 再来" · 双端都核心

---

## 既有资产 / 修改方向 / 新增内容

- **既有资产**：`03-mobile.jsx` 已有雪场详情视觉级 mockup（hero 大图 + 雪场名 + 评分 + 打卡数 + 详情 + 评价）。`06-web-longpage.jsx` 部分覆盖 Website 雪场页。
- **修改方向**：保留视觉结构 + ❗ 特别提醒卡片置顶 + 4 个圆形快速行动按钮（打卡 / 发拼车 / 找教练 / 找地接）。
- **新增**：States 矩阵（雪季外 / 未打卡 / 已打卡 1-3 次 / 4+ 次）+ 底部固定"这周末谁去"模块 + Trust signal 设计。

---

## 页面目标

让用户在 **2 分钟内**决定"我要 / 我不要去这个雪场"。

## 用户心理

- 第一次来的人怕踩坑（❗ 重要）
- 多次来的人想知道"这周有没有熟人也去"

## Primary / Secondary CTA

**小程序**
- Primary：按状态动态切换
  - 未打卡 → 「📍 打卡」
  - 已打卡 → 「🚗 发拼车」
- Secondary：4 圆形按钮 + 底部"这周末谁去"

**Website**
- Primary：「⊕ 加入收藏（扫码同步）」
- Secondary：「📱 扫码进小程序找教练 / 拼车」

---

## States 矩阵

| 状态 | Hero 区显示 | Primary CTA |
|---|---|---|
| **未登录** | 普通 hero | 任一 CTA 触发登录 |
| **未打卡过此雪场** | "还没去过 Stubaier" | 📍 打卡 |
| **已打卡 1-3 次** | "你来过 N 次" + 上次时间 | 🚗 发拼车 |
| **已打卡 4+ 次** | "Stubaier 老熟人" 徽章 | 🚗 发拼车 + 推荐给朋友 |
| **雪季外（5-10 月）** | "冰川夏天也开" + 切换到夏季缆车信息 | 看夏季活动 |
| **当前在雪场 5km 内** | 顶部固定"📍 你在 Stubaier，要打卡？" | 大打卡按钮 |
| **未来 7 天有出行计划** | "你周六会来" + 行前清单链接 | 看清单 |
| **雪场服务异常 / 关闭** | "Stubaier 今日因暴风雪关闭" | 看附近替代雪场 |

---

## Loading / Empty / Error

- **Loading**：骨架屏（hero 大灰色块 + 段落条 + 按钮灰色）
- **Empty**：从未有人打卡 → "成为第一个打卡 Stubaier 的人" + 大打卡按钮
- **Error**：数据加载失败 → "请下拉刷新" + 缓存版本（如果有）

---

## Trust Signals

1. **真实打卡头像**（不假人头）：底部"这周末 X 人去" + 头像 list 可点
2. **教练打卡轨迹**：教练卡片显示"Stubaier 12 次" 真实数字
3. **避坑提示来源**：每条避坑右上角小字"来自 张三 · 2 周前"
4. **评价者真实身份**：评价右侧用户头像可点 → 公开主页

---

## Micro-interactions

- 滚动到 ❗ 特别提醒卡片：震动 1 次 + 卡片轻微闪烁（spring 320ms）
- 4 quick actions 按钮按下：scale 0.96 + ripple
- 打卡按钮按下：scale 1.08 + spring + haptic feedback heavy
- 切换底部"这周末"卡片：自动循环（如果有多个雪场推荐）

---

## 分享机制

- 右上角 share icon → 生成海报
- 海报内容：雪场 hero 图 + 用户头像 + "我推荐 Stubaier Gletscher · 来自趣野 Funwild" + 二维码
- 默认分享文案："Stubaier Gletscher · 冰川 + 公园 · 慕尼黑 2h"

---

## Conversion Logic

| 用户类型 | 来这页的转化路径 |
|---|---|
| 1A Hardcore | 看实用贴士 → 直接发拼车 |
| 1B 周末玩家 | 看❗ 避坑 → 看本周谁去 → 加入拼车 |
| 1C 新手 | 看新手动线 → 看教练 → 联系教练 |
| 2A 高消费家庭 | 看完整内容 → 联系地接 → 客服咨询 |
| 2B 年轻自由行 | 收藏 → 比较其他雪场 → 联系教练 |

## Tokens 引用

- ❗ 特别提醒：`bg = semantic.warning.bg`, `border = warning.border`, `padding = space-4`
- Hero 标题：`text-display-lg (36 / 1.15 / 600 / -1)`
- 雪场副信息：`text-body-sm (13 / 1.55 / 400) + neutral.muted`
- 数字（打卡数 / 评分）：`Geist Mono · tabular-nums`
- 4 圆形按钮：`size = 56px`, `radius = full`, `bg = accent[50]`, `icon = 24px`
- 底部固定卡片：`bg = surface.raised`, `border-top = bd.default`, `shadow = shadow-md`
