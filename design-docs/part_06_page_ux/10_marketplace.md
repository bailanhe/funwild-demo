# 市集 · Marketplace（二手）

> 探索 tab · "市集" segmented · **Year 1.2 优先级**，V1 可后置

---

## 页面目标

让本地华人雪友买 / 卖 / 换二手装备。

## 用户心理

- 卖家：处理不用的装备，回点血
- 买家：花更少钱进圈子
- 信任：线下交易，不冒险

## 筛选

| 维度 | 选项 |
|---|---|
| **类型** | 出售 / 求购 / 交换 |
| **物品** | 单板 / 双板 / 雪鞋 / 服装 / 配件 |
| **运动** | 滑雪 / 攀岩 / 山地车 / 徒步 |
| **品牌** | Nitro / Burton / Salomon / ... |
| **城市** | 慕尼黑 / Wien / 苏黎世 / 米兰 / 其他 |
| **新旧** | 全新 / 95新 / 9 新 / 8 新 |

## 发布模板

- 选填：品牌 / 型号 / 尺寸 / 新旧 / 购买年份 / 原价

## 信任机制

- 卖家信誉：历史交易次数 + 评价 + 徽章
- 买家保护提示：警示卡片置顶
- 举报机制：每条帖子右上小 "举报"
- 三次被举报 → 帖子下架 + 限制发布权限

## 防风险

- 价格字段必填，描述里禁止微信号 / 手机号（自动过滤）
- "建议当面验货付款" 警示
- 平台明确"不参与交易，不承担纠纷"

## B-kuh 导流

- 列表底部固定 "买新的？去 B-kuh 看看" 卡片
- 根据浏览物品分类 → B-kuh 新品推荐

## Tokens

- Grid 2 列卡：`gap = space-3`, `radius = radius-md`
- 价格：`Geist Mono · weight 600 · text-body-lg`
- ⚠ warning：`bg = warning.bg`, `padding = space-3`

## Year 1 决策

- **P1.2 优先级**：V1 上线时市集可暂缓
- 简化版 V1.0：只做"求购 / 出售" + 跳微信对话，无收藏 / 评价 / 举报
- 完整版 V1.2 含信用 + 评价 + B-kuh 导流
