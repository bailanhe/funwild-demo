## 筛选

| 维度 | 选项 |
|---|---|
| **类型** | 比赛 / 训练营 / 体验 / 团滑 / 培训 / 社交 |
| **运动** | 单板 / 双板 / Ski Touring / 攀岩 / 山地车 / 徒步 |
| **组织者** | N47 / 品牌方 / 雪场 / 个人 |
| **日期** | 本周末 / 本月 / 下月 / 全部 |
| **价格** | 免费 / < €100 / €100-500 / > €500 |
| **水平** | 任意 / 新手 / 中级 / 高级 |

## States

| 状态 | 渲染 |
|---|---|
| 默认 | N47 ⭐ 一栏 + 本周末 + 全部 |
| 0 个活动 | "本周末暂无活动，发布一个？"  |
| 你已报名的 | 卡片 corner 显示 "已报名" |
