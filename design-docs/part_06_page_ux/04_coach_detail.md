## 页面目标

让用户在 **90 秒内**决定"我要不要 wave 这个教练"。

## 用户心理

- **2A 高消费家庭**：这个教练能不能教好我家娃？安全吗？
- **2B 年轻自由行**：性价比怎样？颜值如何？
- **1C 新手**：这个教练会不会嫌我太菜？

## Loading / Empty / Error

- **Loading**：骨架屏，头像灰色圆 + 文字条

## Wave 机制详解

### 用户发起 wave

```
用户点 [发起 Wave →]
  ↓
弹层：
  "给张磊发起 wave"
  ┌──────────────────────────┐
  │ 默认消息（可修改）：       │
  │ "你好，我对你的教学感兴趣。"│
  │                          │
  │ 我的滑雪级别：[新手 ▾]    │
  │ 想约的时间：[周六上午 ▾]  │
  │ 想约的雪场：[Stubaier ▾] │
  └──────────────────────────┘
  [取消]  [发送]
  ↓
"已发送！张磊会在 24h 内回复"
  ↓
首页"我的进行中"出现"等待张磊回复"
```

### 教练回复 wave

```
教练在后台 / 小程序消息中心
  ↓
看到 wave + 用户公开主页
  ↓
选择 [接受] / [拒绝] / [稍后]
  ↓
点 [接受] → 自动给用户发"已回复"通知 + 弹"打开微信对话框？"
  ↓
微信对话框打开，自动发了一条：
  "我对你的教学感兴趣。
   级别：新手 / 时间：周六上午 / 雪场：Stubaier"
```

### 防绕单设计

- Wave 后 24h 内的对话视为"平台撮合"
- 平台撮合的订单可以写评价
- 教练绕单（不通过 wave 直接拿微信）的学员**不能写评价**
- → 教练越想要好评价，越要走 wave；越走 wave，平台越有数据

## 分享机制

- 右上角 share icon → 生成海报：教练头像 + 名字 + 资质 + Funwild 二维码
- 教练自己也可以分享自己的页面（提升个人 SEO + 海报中带"Funwild 认证教练"）

## Conversion Logic

| 用户路径 | 决策依据 |
|---|---|
| 看到 Stubaier 攻略 → 联动教练 → 张磊详情页 | 价格 + 语言 + 评价 → wave |
| 在教练列表 → 张磊详情页 | 24h 回复率 + 评价数 → wave |
| 朋友推荐张磊 → 分享链接 → 详情页 | 朋友推荐 + 评价 → wave |

## Tokens 引用

- 头像：`radius-full` (80px 圆) · 真实照片 → 渐变 fallback → 默认头像三段降级
- 评分星：`accent[600]` 填充
- 价格：`Geist Mono · tabular-nums · weight 500 · text-h2`
- 24h 回复率：`semantic.success.fg` 文字 + `semantic.success.bg` 背景 tag
- Wave 按钮：`bg = accent[600]`, `text = white`, `radius = radius-sm (4)`, `padding = space-3 space-6`
- 评价分类标签：`bg = neutral[100]`, `text = neutral.muted`, `tag pattern`
