# 公开个人主页 · Profile (Public)

> V1.1 上线 · Website 友好 SEO 资产 · 用户的"ski profile"

---

## 页面目标

让陌生人 / 关注者在 **20 秒内**判断"这个人靠不靠谱"。

## 用户心理

- **被看者**：希望自己看起来体面 + 专业 + 有趣
- **看者**：想知道这个人是谁 / 滑哪 / 靠谱不

---

## URL

## 隐私控制

公开主页可见性（用户在设置中控制）：
- **全部用户**（默认 V1.1 选项）
- **仅关注者**
- **仅自己**

**默认**：V1.1 上线时让用户主动开启公开。不默认全公开（GDPR 友好）。

---

## States

| 状态 | 渲染 |
|---|---|
| 公开 | 完整内容 |
| 仅关注者 | 显示头像 + 名字 + "需要互相关注才能查看"按钮 |
| 仅自己 | 404 公开主页（陌生人看不到） |
| 用户自己访问 | 显示编辑按钮 |
| 已关注用户访问 | "关注" 按钮变 "已关注" |

## Trust Signals

- 雪场打卡轨迹（真实数据）
- 信用分公开
- 攻略阅读数公开
- 行为日志公开（透明）

## SEO

- 标题：`<NAME> · 趣野 Funwild 用户主页`
- meta description：`<NAME> 在 [雪场] 滑雪 N 次，已解锁 X 徽章。在趣野 Funwild 上关注他。`
- schema.org Person markup
- Open Graph 卡片 = 海报视觉

## 分享

- 顶部分享 → 生成"我的 ski profile"海报 + 二维码

## 小程序版

小程序内访问公开主页：
- 简化版（不显示 SEO meta）
- 关键信息 + 关注按钮 + 看其攻略
- "在浏览器查看完整版" 入口

## Tokens

- Hero：`bg = surface.raised`, `padding = space-8`
- 雪场打卡 row：等宽 mono 数字 + tabular-nums
- 攻略卡：`radius = radius-md`, hover 微浮起
- 活动日志：timeline-style，左侧 dot + 时间
