# 地接列表 · Outfitter List

> 探索 tab · "地接" segmented · 主要服务类型 2 国内游客

---

## 页面目标

让用户在 **60 秒内**找到 1-2 个匹配的地接候选。

## 用户心理

- **2A 高消费家庭**：哪家有家庭定制 + 安全保障好
- **2B 年轻自由行**：哪家性价比 + 体验好
- **2C 轻奢**：哪家高端 + 不大众

## 筛选

| 维度 | 选项 |
|---|---|
| **服务类型** | 滑雪地接 / 户外 / 青训 / 定制旅行 / 单项 |
| **目的地** | 奥地利 / 瑞士 / 德国 / 意大利 / 法国 |
| **行程天数** | 1-3 / 4-7 / 8-14 / > 14 |
| **人群** | 家庭带娃 / 情侣 / 朋友 / 单人 / 企业 |
| **价格** | < €1000 / €1000-3000 / €3000-5000 / > €5000 |
| **特性** | 含保险 / 含中餐 / 含装备 / 中文翻译 |

## States

| 状态 | 渲染 |
|---|---|
| 默认 | N47 ⭐ + 商业地接分组 |
| 0 个匹配 | "未找到，[我要定制 →]" 大按钮 |
| 已收藏 | corner 显示心形 |

## "我要定制" 入口

→ 跳转到定制需求表单页（V1）：目的地 + 时间 + 预算 + 人数 + 备注 + 联系方式 → 提交后客服 24h 内联系

## Trust Signals

- "已成团 N 次" 真实数据
- N47 ⭐ 金标
- 评分基于真实团员

## Tokens

- 地接卡：和雪场 / 活动卡同 pattern
- "我要定制" 大 CTA：`bg = accent[600]`, padding 大
