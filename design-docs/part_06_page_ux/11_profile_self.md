## 设置子页面

### 外观
```
设置 → 外观
├── Sunset · 雪场夕阳调（默认）       ⊙
├── Pine · 松林墨绿调                ○
└── 跟随系统（dark mode 自动）        □
```

### 通知偏好
```
设置 → 通知
├── 周三晚拼车推送       □ 开 / 关
├── 行前 7 天清单         □ 开 / 关
├── Wave 回复             □ 开 / 关
├── 徽章解锁              □ 开 / 关
├── 关注的人动态          □ 开 / 关（V1.1）
└── 系统通知              □ 开 / 关
```

### 隐私（V1.1）
```
设置 → 隐私
├── 公开主页 可见性
│   ○ 全部用户
│   ○ 仅关注者
│   ⊙ 仅自己
├── 雪场打卡 公开度
├── 徽章墙 公开度
└── 数据下载 / 删除（GDPR）
```

## States

| 状态 | 渲染 |
|---|---|
| 新用户 | 徽章 1 / 50 + "完成 onboarding 再解锁更多" |
| 老用户 | 完整 dashboard |
| 教练身份 | 多 1 个"教练后台"入口 |
| 地接身份 | 多 1 个"地接后台"入口 |
| 未关注任何人 | 我的关注模块隐藏 + hint "去关注雪友" |

## Trust Signals

- 信用分公开（增强自律）
- 邀请码可复制 → 海报 + 二维码
- 隐私设置透明

## Micro-interactions

- 头像点击：放大 + edit 选项
- 徽章卡片：渐进加载 + 进度条动画
- "我的进行中"卡片：左滑可标记完成

## Tokens

- Profile hero：`bg = surface.raised`, `padding = space-6`
- 大入口卡（徽章墙）：`bg = accent[50]`, `border-left = 3px accent[600]`
- 设置 row：`padding = space-3 space-4`, `border-bottom = bd.subtle`
