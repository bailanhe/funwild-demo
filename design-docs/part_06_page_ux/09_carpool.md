# ★ 拼车 / 出行 · Carpool

> retention-critical · Year 1 决定生死的功能 · 比雪搭子至少好 3 倍

---

## 既有资产 / 修改方向 / 新增内容

- **既有资产**：无单独拼车页 mockup（既有 mockup 是首页 + 雪场，拼车未画）。
- **新增**：全新 wireframe + wave 机制 + 自动匹配 + 信用分 + 4 视图（本周末 / 所有出行 / 我发布的 / 我加入的）。

---

## 页面目标

让用户在 **2 分钟内**找到 / 发布一个拼车计划。

## 用户心理

- **1A Hardcore**：找同级别雪友，不被新手拖
- **1B 周末玩家**：周末有人组局
- **1C 新手**：求带，不要被嫌弃

## States 矩阵

| 状态 | 渲染 |
|---|---|
| **可申请加入** | 申请按钮 + 已加入头像 list |
| **已申请，等审批** | "申请已发，等发起人确认" + 灰色按钮 |
| **已加入** | "你已加入，集合地点：..." + 微信对话框入口 |
| **已满** | "已满" 红色 + "加入候补" |
| **截止前 24h** | warning 色 + 倒计时 |
| **过期已发生** | "活动已结束 + 打卡了吗？" → 打卡链接 |
| **发起人取消** | "拼车取消" + 推荐类似 |
| **我是发起人** | 显示 "X 人申请待审批" + 编辑入口 |

## Wave 机制 · 拼车版

```
用户点 [申请加入]
  ↓
弹层：
  "申请加入 周六 Spitzingsee 拼车？"
  ┌──────────────────────────┐
  │ 你的级别 自动填：中级       │
  │ 备注（可选）：              │
  │ "我有装备，可以分摊油费"    │
  └──────────────────────────┘
  [取消]  [发送申请]
  ↓
"申请已发送，张三会在通知里收到"
  ↓
张三在小程序消息中心：
  "李四申请加入你的拼车"
  + 李四公开主页 link
  + 信用分 + 历史拼车次数
  ↓
张三选 [接受] / [拒绝]
  ↓
接受 → 双方收到通知 + 微信对话框打开
拒绝 → 李四收到"位置可能已满"（不告知具体拒绝理由）
```

## 信用分系统

### 计分规则
- 准时成行：+2
- 主动取消（24h 前）：+0
- 临时取消（24h 内）：-2
- 缺席无通知：-5
- 收到表扬：+1
- 收到投诉：-3

### 信用分展示
- 用户公开主页：信用分 95 + "诚信雪友" 徽章
- 拼车详情页发起人头像旁：信用 95
- 信用 < 70 不能发起拼车，只能加入
- 信用 < 50 进入"低信用名单"，发起人看到 warning

### 防滥用
- 发起人不能给申请者打"投诉"（避免恶意打分）
- 投诉需要双方都打"成行"后才允许
- 每月信用分恢复机制（新用户给 90 起步）

---

## Trust Signals

1. 发起人公开主页 + 信用分
2. 已加入用户头像 + 等级 + 信用
3. "诚信雪友"徽章
4. 24h 取消政策透明

---

## Loading / Empty / Error

- **Loading**：骨架屏
- **Empty 本周末无拼车**：显示"本周末暂无拼车，发起一个？"+ 大 FAB
- **Empty 我发布的**：显示"还没发布过出行，试试看？"
- **Error**：申请失败 → 提示原因 + 重试

---

## Micro-interactions

- 拼车卡片进入：从右滑入 fade 200ms
- 申请加入按钮按下：scale 0.96 + spring 弹层
- "还差 X 位"数字变化：tabular-nums + 颜色渐变（绿 → 黄 → 红）
- 头像 list：水平滚动 momentum + bounce

## 关注 / 互相关注的自动 trigger

```
拼车成行 + 一周后
  ↓

  "你和 X 一起去过 Spitzingsee，互相关注吗？"
  [关注] [稍后]
  ↓
点 [关注] → 默认双向（X 自动收到"想关注你"）
```

## 分享机制

- 拼车计划生成"招募海报"：雪场图 + 日期 + 还差 X 位 + 二维码
- 默认分享到微信群（拼车海报多数是群内传播）
- 朋友圈分享比例低，但生成时仍提供选项

## Conversion Logic

| 用户路径 | 决策依据 |
|---|---|
| 周三晚 push "本周末谁去" → 拼车 list → 申请 | 看发起人 + 已加入人 → 申请 |
| 雪场详情底部"这周末谁去" → 申请 | 同上 |
| N47 群消息分享 → 详情 → 申请 | 群友推荐 |
| 自己发布 → 等加入 | 等候 |

## Tokens 引用

- 拼车卡：`bg = surface.raised`, `radius = radius-md (6)`, `padding = space-4`, `shadow = shadow-sm`

- 信用分：< 70 `danger.fg` / 70-90 `warning.fg` / > 90 `success.fg`
