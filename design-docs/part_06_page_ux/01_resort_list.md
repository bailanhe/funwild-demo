> 探索 tab · "雪场" segmented

---

## 既有资产 / 修改方向 / 新增内容

- **既有资产**：`03-mobile.jsx` 首页有"雪场推荐 horizontal scroll"作 mockup。
- **新增**：完整列表页 + 筛选 + 排序 + 卡片设计。

---

## 页面目标

让用户在 **30 秒内**按意图筛选到目标雪场（≤ 5 个候选）。

## 用户心理

- "周末附近哪个雪场可以去？" → 按车程筛
- "我新手适合哪个？" → 按难度筛
- "有什么值得去的？" → 按打卡数排序

## 筛选项

| 维度 | 选项 |
|---|---|
| **国家** | 全部 / 德国 / 奥地利 / 瑞士 / 意大利 |
| **车程** | < 1.5h / 1.5-3h / 3-5h / > 5h |
| **难度** | 新手 / 中级 / 高级 / 专家 |
| **运动** | 单板 / 双板 / 都适合 / 公园 / 野雪 |
| **特性** | 冰川 / 夏季开放 / 公园 / 大雪区 / N47 合作 |

## 排序

- 热门（默认）= 打卡数 + 评分 + 关注度
- 车程（最近优先）
- 评分（高分优先）
- 雪季新开（最新优先）

---

## States

| 状态 | 渲染 |
|---|---|
| 默认 | 18 雪场全部 |
| 筛选后无结果 | "未找到雪场，调整筛选" |
| 雪季外 | 雪场卡显示"冬季未开放"灰色 + 冰川雪场显示"夏季开放"绿色 |

## Trust Signals

- 真实打卡数（不假数）
- ❗ 避坑预告卡片直接出现在列表
- 评分基于平台撮合订单评价

## Micro-interactions

- 卡片进入：stagger 50ms fade
- 筛选 chip 切换：触发 list 重新排序动画
- 卡片点击：scale 0.98 + 跳转

## 分享

- 单个雪场卡片可右滑分享

## Tokens

- 卡片：`radius = radius-md (6)`, `padding = space-4`, `shadow = shadow-sm`
- 筛选 chip：`radius = full (pill)`, `bg = sunken`, selected `bg = accent[100]`
- 难度星：`accent[600]` 实心 + `neutral[300]` 空心
